# 预置图标清单（Tabler 描边图标，24×24，共 28 个）

用法：看中哪个，把它的标记原样放进 .ico 的 svg 里，例如
<svg class="ico" viewBox="0 0 24 24"><path d="M3 17l6 -6l4 4l8 -8"/></svg>
描边、颜色、粗细都由组件库接管：不要在 path 上自己加 stroke/fill/width 属性。
两条纪律：只许从这里复制，禁止自己画 path（手绘出来的就是不成形曲线团）；
清单里没有合适的就不放图标——每个标题都配图标在反撞衫名单上。
