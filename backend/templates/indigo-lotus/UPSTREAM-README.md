# indigo-lotus（青莲碧蓝 · 梦幻国风）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/indigo-lotus`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：青莲 #5F469A（深紫带蓝调）到碧蓝 #6BC4CA（薄荷青蓝）的垂直渐变做黄昏海天，
  纯白 #FFFFFF 提亮星光与云纹，浅灰 #E0E0E0 作辅助文字。
- 意象：流动云层（水墨晕染、透明度 30%-50%）、星光（白点 + 光晕）、水面波纹
  （细线反射）、月亮；远景剪影只留极简轮廓。
- 排版：标题字号大、留白多，笔画柔和带文化感；副标题细无衬线；文字以白色为主。
- 布局：垂直分层——上天空（紫）、中云层、下水面（蓝）；正文卡片用半透明白底 +
  毛玻璃感浮在画面上。
- 禁忌：不要高饱和暖色、霓虹色；不要硬朗几何、锐利边角；不要商业感强的柱状图与
  KPI 卡；不要衬线粗体或英文 Grotesk；不要把画面塞满。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 上游的云层、星光、月亮、水面波纹全部改为 CSS ambient 层：渐变底 + 波纹画在
  .slide 背景上，云雾星光是 .slide::before（data-URI SVG），月光圆是 .slide::after
  （radial-gradient + 柔光 box-shadow），全部 z-index:-1，每页自动衬底、不进骨架。
- 渐变端点保持上游身份色 #5F469A → #6BC4CA，仅把中段两档（30%/68%）略微压暗
  （#5C4F9E / #4F86A2），保证上半区白色细体文字的对比度；letterbox 底色取渐变
  中段 #61779F，翻页时页面外底色不跳。
- 上游预览底部的三格数据小卡（lotus-card）发展成 metrics 版式的月光数据
  （白色细体大数字 + 细白顶线），符合上游"不要 KPI 卡"的禁忌——只用大数字不用图表。
- 强调色只用白：白底药丸、白底按钮、月光白数字；未引入朱砂等暖色。
- 字体栈：Inter（拉丁可变字重）+ Noto Sans SC（中文 300/500），标题 300 细体大字距；
  不新增 webfont 文件。
