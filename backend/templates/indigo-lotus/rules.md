# 青莲碧蓝 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律细无衬线大字距（h1/h2 已内建 300 字重 + 宽字距 + 白色），小标题 500 字重
  （h4 已内建），正文细体浅灰。不要改成衬线粗体、不要用英文 Grotesk 粗黑
  （上游禁忌），不要给标题加颜色。
- 语气沉静有诗意但不空：写具体的夜、灯、书目与人话（像「江心岛书房为我们留灯」），
  诗意放在意象里，不放在口号里。
- 数字与英文用 Inter 细体（il-stat-v 已内建），月光白发光效果是模板自带的，不要复刻。

## 结构纪律（白是身份，留白是呼吸）

- 文字一律白色（--ink）与浅灰（--ink-2 / --ink-3）；强调只准用白：白底药丸
  （il-pill-accent）、白底按钮（il-btn）、月光白数字（il-stat-v）。
  禁朱砂、金黄、荧光等一切高饱和暖色与霓虹。
- 卡只有玻璃卡一种：半透明白 + 细白描边（il-card），keynotes 一页至多一组三张，
  禁再加阴影、禁再叠渐变、禁深色实底卡。
- 深色渐变底、云雾星光与月光圆是模板自动衬底，正文不要画天空、不要叠光效。
- 一页最多两组内容块 + 页脚；竖排 il-vert 只放留白处，一页至多一条，
  内容是诗句或四字短语，禁放正文数据。

## 禁令

- 禁 emoji；禁高饱和暖色、禁霓虹色、禁锐利边角与硬朗几何（按钮圆角 4px 已是上限）。
- 禁商业感强的柱状图与 KPI 卡：数据用 metrics / moments 的细体大数字呈现，
  不要引入图表组件。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁把画面塞满：宁可少一块内容，也要给夜空留出呼吸。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回
  （hero/quote 版式豁免）；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 航程顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是全篇的压轴一笔。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
