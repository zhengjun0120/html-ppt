# 墨页叙事 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律衬线（h1/h2 已内建 Georgia/宋体栈），元数据与标签一律等宽（ei-folio / ei-cap / ei-pill / deck-footer 已内建），两套字体建立「纸面 + 页码」的阅读秩序。不要用无衬线做标题，不要给元数据换花体。
- 语气要「长文作者」：写走访、样本与一句原话（像"店主说，图书是让顾客进门的那部分"），不写评论腔。
- 数字用衬线大字呈现（ei-stat-v 已内建），口径与来源一律等宽小字（ei-cap）。

## 结构纪律（无彩色，靠秩序）

- 全模板没有任何彩色：纯黑 #0A0A0B 是唯一强调色。需要「强调」时用黑底反白（ei-pill-accent / ei-card-ink），禁引入任何色相。
- 线只有一种粗细：1px 细线（ei-rule / ei-card / ei-item / ei-tl 自带）；数据页上边线 2px 是唯一加重。禁粗黑大色带、禁阴影、禁圆角。
- 反转面（墨黑实块）整页最多一个：ei-card-ink 与 ei-pill-accent 不同时大面积出现，正文页保持纸灰安静。
- 留白比卡片更重要：一页最多两组内容块 + 页脚；卡片能用细线描边就不用填充。

## 禁令

- 禁 emoji；禁任何彩色、渐变、金属流光或玻璃拟态——墨水屏没有这些。
- 禁 AI 腔；报告的分量来自样本、口径与受访者的原话。
- 禁编造精确数字：走访数据必须给口径与来源（页尾等宽字），没有来源就写区间或中位数。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；比较类内容用 keynotes 三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：样本与账目一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 长文顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是长文的「压轴引语」。
- divider 在 8 页以上的 deck 至少出现 1 次；反转面页与安静页穿插，不要连排墨黑块。
