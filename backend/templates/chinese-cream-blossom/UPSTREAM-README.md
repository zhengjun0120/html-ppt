# chinese-cream-blossom（中国传统色·米白樱粉）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/chinese-cream-blossom`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：樱粉 #F091A0、淡樱 #F5BFC8 为主色，宣纸米 #F5F2E9、象牙白 #FAF7F0 做背景；
  文字墨黛 #3D3D3D、暖灰 #7A6B5D；强调胭脂红 #B23A48（印章、关键数据）；点缀淡金 #D4A574、暖米 #E8DCC8。
- 排版：标题宋体加粗或楷书风、字距宽松，副标题行楷樱粉，正文宋体行高 1.9，引文古风衬线。
- 意象：樱花、桃花瓣、云气、团扇、灯笼；装饰淡彩晕染、细线、圆点、印章、回纹；柔软曲线，避免锋利几何。
- 布局：大面积留白 + 主体偏左或居中；信息卡片用淡色块、圆角小；色块与留白节奏柔和。
- 适合：女性品牌、婚庆喜事、春季节庆、美妆护肤、温柔向生活方式。
- 禁忌：高饱和荧光、暗黑背景、锋利几何、硬朗金属、过度装饰、赛博或工业风。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（樱花枝 + 色卡列表）；本模板按本仓库 deck-v2 契约
  重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 预览右上角的樱花枝收进 ambient 层：两簇圆瓣花（CSS data-URI SVG，五瓣椭圆 + 淡金花蕊，
  透明度压到 0.28-0.5）+ 左下三片飘落花瓣（.slide::before/::after，z-index:-1），
  每页自动衬底、不进骨架；比上游预览更收着，规则里明确禁止生成侧再叠花瓣。
- 预览左侧竖线色卡的"border-left 4px"语汇升级为全模板唯一卡型 cb-card（左线暖卡），
  圆角收小到 10px（上游"圆角小"的要求），与凝脂杨妃的釉面色卡、故宫墨红的大圆角厚卡形成三套手感。
- 关键数据与印章用胭脂红 #B23A48（上游明确分工）；按钮为樱粉实底 + 墨黛字（胭脂留给印章，
  且白字在 #F091A0 上对比度不足），与凝脂杨妃的胭脂实底按钮区分开。
- 字体栈：标题 'Songti SC'/'STSong'/'SimSun' 系统宋体，小标题 'STKaiti'/'KaiTi'，
  小字 'Noto Sans SC'（自托管）；不新增 webfont 文件。
