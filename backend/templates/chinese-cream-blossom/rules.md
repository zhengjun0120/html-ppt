# 米白樱粉 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律宋体加粗宽字距（h1/h2 已内建宋体栈），小标题与条目名用楷体（h4 / cb-t / cb-stat-l 已内建楷体栈），小字标签用无衬线细字（cb-kicker / cb-pill / deck-footer 已内建）。不要引入黑体粗标题、手写花体或圆体。
- 语气要「有温度的具体」：写人、写时令、写动作（像"三月的风把请柬吹到了桌上"），不写抽象大词。
- 数字与英文用无衬线呈现（模板已内建），不要给数字加楷体；大数字只出现在 cb-stat-v。

## 结构纪律（樱粉是温度）

- 樱粉只用于柔性元素：花影衬底（模板自带）、樱线 cb-line、卡左线 cb-card、花圈 cb-n、按钮 cb-btn。禁把樱粉做成大面积粉底色块。
- 胭脂只允许出现在五处：小印 cb-seal、强调胶囊 cb-pill-red、关键数据（cb-stat-v / cb-tl-t）、竖排重点字 cb-vert-accent。禁把胭脂用于大标题或整卡底色。
- 淡金只做花蕊级小点缀（模板衬底里已有），正文与组件不再引入金色。
- 卡只有一种：左竖线暖卡 cb-card（象牙半透明底 + 樱粉左线 + 小圆角），无阴影。
- 留白即呼吸：一页最多两组内容块 + 页脚；竖排 cb-vert 只放留白处，一页至多一条。

## 禁令

- 禁 emoji；禁高饱和荧光、暗黑背景、硬朗金属、赛博或工业风、锋利几何装饰。
- 禁再叠加花瓣/花卉装饰——花影每页一组，模板已衬底，生成侧不画。
- 禁 AI 腔（口号式动词、营销形容词，换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 花笺顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是花笺的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
