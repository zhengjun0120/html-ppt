# 极光 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线：标题 800 字重（h1/h2 已内建星白微光），正文常规字重宽行距；小字标签用 600 字重宽字距（au-kicker / au-pill / deck-footer 已内建）。不要引入衬线标题、手写体或圆体。
- 语气要「夜里赶路的人」：写地点、指数、时刻与人话（像"云图开了个口子，发车"），不写抽象大词。
- 数字与英文用无衬线呈现（模板已内建），关键数字交给 metrics，不要埋进句子里。

## 结构纪律（极光是身份）

- 深色底纪律：正文一律浅色（星白 #F1F5FF / 浅靛 #C3CDF2 / 小字 #8E99CE），卡只有暗夜玻璃一种（au-card，绿边强调用 au-card-glow）。禁白色实底卡、禁纯黑死底、禁在深底上用深色文字。
- 极光渐变只允许出现在四处：标题带细线（au-band / au-kicker 自带）、大数字（au-stat-v）、引文（au-quote）、行动钮（au-btn）。禁把渐变铺成大面积色块或用于正文文字。
- 天幕、极光带、星野与山脊住在 ambient 层，由模板自动衬底；不要在骨架里手画光带、星星或剪影。
- 徽章 au-badge 是全模板唯一的方块身份件，一页至多一枚；药丸不要超过两枚一排。

## 禁令

- 禁 emoji；禁荧光色、金属质感、纯白背景——这个风格是「深蓝天幕上的光」。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的点位、指数与时刻）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），KP 指数一类指标注明机构口径。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，口径写进卡内或页尾。

## 节奏

- 追光顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是天幕最亮的一帧。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
