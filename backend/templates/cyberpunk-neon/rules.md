# 赛博霓虹 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题冷白 900 字重自带霓虹辉光（h1/h2 已内建 text-shadow），正文 #CBD5E1 冷灰白；标签、参数与数字一律等宽（cn-kicker / cn-pill / deck-footer 已内建）。不要引入衬线或手写体。
- 语气要「未来已来」：短促、现在时、像从终端里敲出来的判断（像"雨停后半小时，光最足"），不写客套话。
- 器材参数（ISO / 光圈 / 快门 / 焦段）与日期一律等宽呈现（模板已内建），不要换字体。

## 结构纪律（霓虹是身份，不是正文）

- 双霓虹分工：粉 #FF2E88 管结构与边框（cn-card / cn-pill / cn-stat 顶线 / cn-btn），青 #00F0FF 管数据与高亮（cn-stat-v / cn-tl-t / cn-n / cn-kicker）。禁把霓虹色用于正文段落。
- 正文永远冷白 #F8FAFC 或灰白 #CBD5E1，保证量测对比度；发光（text-shadow）只给标题、数字与线条，正文段落禁加。
- 灰蓝 #7C86A0 只准用于页脚、来源行与单位，不准当正文色。
- 卡只有一种：半透明夜幕底 + 粉描边 + 微光（cn-card）。禁白底、禁大面积荧光色块。
- 故障网格、霓虹横线与扫描带是 ambient 层，模板自动衬底，骨架与正文都不画。

## 禁令

- 禁暖色调、柔和圆角大卡、玻璃拟态；禁让暗色变得沉闷（能量靠霓虹点缀，不靠加亮背景）。
- 禁大面积荧光底色：霓虹只做描边、数字与点缀，铺满一页就算事故。
- 禁 emoji；禁 AI 腔（口号式动词、营销形容词一律换成具体的参数与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是夜行的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
