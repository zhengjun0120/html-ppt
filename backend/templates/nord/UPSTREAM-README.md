# nord（北欧）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/nord`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。
（Nord 本身是开源社区配色体系，上游 oh-my-ppt 对其做了演示向的适配。）

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：标题 #eceff4 极浅灰白、正文 #d8dee9 浅灰，强调 #88c0d0 冰蓝与 #81a1c1 钢蓝是
  极夜里仅有的光；背景 #2e3440 → #434c5e 的深灰蓝渐变模拟极夜天幕；卡为
  rgba(46,52,64,0.75) + rgba(136,148,164,0.2) 细如地平线的描边。
- 排版：冷静的无衬线，字重轻到中等，标题不张扬但清晰存在，行距宽松。
- 布局：极简，每页只承载一个核心信息；大面积深色留白是思考的空间。
- 装饰：极光薄雾、霜蓝细线、四周边框，克制到近乎无。
- 适合：基础设施介绍、云产品发布、技术架构分享、哲学式技术演讲。
- 禁忌：暖色调或活泼元素、塞满内容、霓虹或高饱和色彩、暗底小字号。

## 转换说明

- 上游只有一个 16:9 单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约重建为
  10 版式骨架（9 基础 + code，深色科技类按规范附加代码版式）。
- --bg 取背景渐变的中段值 #3b4252：letterbox 底色随页面翻动不跳色。
- 顶部极光薄雾与四周霜蓝细框做成 .slide::before/::after 的 ambient 层（z-index:-1，
  纯 CSS 渐变与描边），每页自动衬底、不进骨架；不用辉光，克制即身份。
- 键牌（no-key，键帽样式）是本模板的专属身份元素：服务「编辑器与终端」类叙事，
  只装真实快捷键或短命令。
- 字体栈：Inter（拉丁无衬线）+ Noto Sans SC（中文），代码/编号/键牌用 JetBrains Mono
  （随 fonts.css 自托管），不新增 webfont 文件。
- demo 叙事为原创（极简工作流：编辑器与终端），数据口径写在页内来源行。
