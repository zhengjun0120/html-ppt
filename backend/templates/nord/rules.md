# 北欧 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 冷静的无衬线（Inter + Noto Sans SC，已内建），字重轻到中等：h1/h2 是 600、lede 是 300、大数字 300，不要再加粗；编号、时间点、代码用等宽（JetBrains Mono，已内建）。
- 语气要「深思熟虑的少」：写取舍、按键、配置与人话（像"启动 1.8 秒，快到不需要启动页"），不写抽象大词。
- 行距宽松是模板内建的（lede 1.95），不要用密排文字破坏呼吸感。

## 结构纪律（冰蓝是仅有的光）

- 冰蓝 #88C0D0 只允许出现在：题签发丝、编号（no-n）、大数字（no-stat-v）、时间点（no-tl-t）、按钮、accent 标签与键牌文字；钢蓝 #81A1C1 只做次级陪衬。禁霓虹、禁辉光、禁渐变彩色。
- 卡只有一种：暗色半透明 + 细描边小圆角（no-card）。禁硬阴影、禁亮色底、禁玻璃拟态。
- 键牌（no-key）只装真实快捷键或短命令，一页至多 2 枚；禁把长句塞进键牌。
- 大面积的深色留白不是空白，是思考的空间：一页最多两组内容块 + 页脚。

## 禁令

- 禁 emoji；禁暖色调与活泼元素；禁霓虹或高饱和色彩；禁辉光与金属质感。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁整页长代码——配置是主角时只放一段（code 版式 6-10 行）。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → code → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是极夜里的「压轴一颗星」。
- divider 在 8 页以上的 deck 至少出现 1 次；code 一份 deck 至多 2 页，且要与数据页或内容页穿插。
