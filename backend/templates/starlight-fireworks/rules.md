# 一半星河一半烟火 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律衬线气质（h1/h2 已内建 Georgia/宋体衬线栈），正文无衬线细体、行距 1.9；小字标签用无衬线（sf-kicker / sf-pill / deck-footer 已内建）。不要引入黑体粗标题、圆体或手写花体。
- 语气要「有体温的浪漫」：写具体的人、时刻与动作（像"零点那一刻，两城同时抬头"），不写抽象口号。
- 数字与英文用无衬线呈现（模板已内建），不要给数字加衬线斜体。

## 结构纪律（双意象是身份）

- 星光金只允许出现在四处：星月徽章 sf-moon、题签细线（sf-kicker 自带）、关键数据（sf-stat-v / sf-tl-t）、金色药丸与按钮（sf-pill-accent / sf-btn）。禁把金色用于整段正文或大面积色块。
- 烟火橙只活在 ambient 层（右下粒子）与对角渐变里，正文与卡片不准出现橙色元素；保持「星河银白 × 烟火暖金」的二元，不引入第三种高饱和色。
- 卡只有一种：半透明深蓝底 + 银细描边（sf-card）。禁硬阴影、禁纯白死底、禁玻璃拟态模糊。
- 星月徽章一页至多一枚；它是构图的重音，不是图标库。
- 留白让粒子呼吸：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉夜空。

## 禁令

- 禁 emoji；禁荧光色、金属渐变、密集烟花墙、办公室商务风。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的场景与人话）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 晚会顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是焰火落幕前的「题记一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
