# 初心红典 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律衬线大字气质（h1 金渐变、h2 金色，已内建 Georgia/宋体栈），小字标签用等宽（rc-kicker / rc-pill / deck-footer 已内建）。不要引入无衬线粗标题、手写体或圆体。
- 语气要「有分量的具体」：写人名、事迹、数字与时间（像"十二年，同一道工序"），不写空泛口号。
- 数字与年份用衬线体呈现（模板已内建），口径与来源用等宽小字。

## 结构纪律（鎏金是身份）

- 金色只允许出现在五处：金线（rc-kicker / rc-line 自带）、徽记 rc-emblem、标题（h1 金渐变 / h2 金色）、关键数据（rc-stat-v / rc-tl-t / rc-pill-accent）、星点 rc-stars。禁把金色用于大面积色块、整卡底色或正文文字。
- 卡只有一种：深红暗部半透明 + 细金描边（rc-card），无圆角无阴影。禁玻璃拟态、禁纯白大底、禁厚重金色光晕。
- 对称即庄重：标题与金线保持左起或居中一条轴线，一页最多两组内容块 + 页脚，不要塞第四块挤掉分量感。
- 星点 rc-stars 一页至多一条，只放留白处，禁当分隔线用。

## 禁令

- 禁 emoji；禁荧光色、霓虹、彩带礼花等喜庆元素——这是典礼，不是联欢。
- 禁 AI 腐（口号式动词堆叠）；表彰写事迹与标准，不写形容词串。
- 禁编造精确数字：评优数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；奖项与事迹用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：评优规模与数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 典礼顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是致辞的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
