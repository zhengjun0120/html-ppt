# 泼彩抽象·多巴胺 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律特粗无衬线（h1/h2 已内建 900 字重），正文无衬线 Medium 气质、行高 1.7；数字与英文用大号粗体或等宽（sp-n / sp-tl-t / sp-stat-v 已内建）。不要引入衬线、书法体或细弱字重。
- 语气要「有现场感的直白」：写颜色、材料、动作与人话（像"颜色第一次不用讲道理"），展签腔而非论文腔。
- 数字用五色轮换大号呈现（sp-stat-v 模板自动上色），禁给数字额外描边或渐变。

## 结构纪律（一页一个爆点）

- 五色（橙红/品红/紫罗兰/青绿/亮蓝）只出现在轮换身份件上：sp-n 编号块、sp-tl-dot 圆点、sp-stat-v 大数字由模板按序自动轮换——禁手写内联颜色、禁自创新色块。
- 明黄只做题签底（sp-kicker）与爆点星芒（sp-burst）；星芒一页至多一枚，只放留白处。
- **对比度铁律**：正文与卡内文字一律深墨实色（骨架内联色已写好，照抄）；白字只出现在五色圆点（特大号数字）与深墨按钮上；禁五色作正文文字色、禁彩底压小字。
- 卡与钮只有一种画法：粗黑描边 + 硬阴影（sp-card / sp-stat / sp-btn）。禁软阴影浮动卡、禁彩色填充卡堆满页面——上游明令「不要用彩色卡片堆满页面」。
- 泼彩是 ambient 底色不是内容区：禁在骨架里手画泼墨 SVG 或彩虹色块。

## 禁令

- 禁 emoji 表情符号（星芒与泼彩由模板提供，骨架不画）。
- 禁低饱和沉闷、暗黑底、严肃商务排版；禁小字密集排版。
- 禁单一主色通篇——五色轮换由身份件自动承担，正文区保持暖白深墨。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的展签语言与现场动作）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 策展顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是艺术家引言的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
