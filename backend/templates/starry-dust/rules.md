# 星屑柔光 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律圆体气质（h1/h2 已内建圆体栈），正文圆润无衬线宽行距；不出现衬线宋体标题与严肃黑体大字。
- 语气像睡前故事：写具体的小物件与小动作（像"把今天轻轻收好"），不写营销大词与抽象口号。
- 数字与英文用无衬线呈现（模板已内建），不给数字加圆体以外的装饰。

## 结构纪律（星光是身份）

- 暖金星光只允许出现在四处：题签胶囊的 ✦（sd-kicker 自带）、渐变线 sd-line、数据顶线（sd-stat 自带）、散点 sd-spark。禁拿星光金当正文文字色。
- 紫罗兰是墨色也是唯一深色：大标题、按钮 sd-btn、徽章 sd-badge、大数字 sd-stat-v。香槟粉与雾紫只做底、线、胶囊底纹，不做文字色（糖果粉文字 #8A4A66 除外，模板已内建）。
- 卡只有一种：棉花糖白 sd-card；薰衣草糖卡 sd-card-tint 仅限 split 右列。大圆角 + 柔影，禁直角卡、禁深色卡、禁生硬描边。
- 留白即构图：一页最多两组内容块 + 页脚；月光碎星与云朵是自动衬底，正文不要再画星星。

## 禁令

- 禁 emoji（✦ ✧ 星形字符是模板母题，允许）；禁高饱和荧光色、金属渐变、玻璃拟态、深暗背景、锐角几何。
- 禁 AI 腔（口号式动词、营销形容词一律换成孩子与睡前场景的人话）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 星轨顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是睡前的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
