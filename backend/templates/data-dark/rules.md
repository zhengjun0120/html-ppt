# data-dark · 质量规则

- gd-ambient/gd-snum 是模板家具：ambient 背景层每页保留原样，snum 写章节编号（01-08）。
- 玻璃卡色（blue/green/warm）是语义：冷数据用 blue、正向用 green、风险用 warm，不要随机选。
- gd-big 彩虹大字一页只允许 1 个；数字必须真实或标“估算”。
- gd-cmd 行以 $ 开头；命令与输出必须真实可复现，不编造运行结果。
- 禁 emoji。

## 密度

- 每页可见文字 100-200 字（代码页另计）；低于下限会被写入门禁直接拒收。
- 卡片说明 22-45 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回。
- **数字纪律**：关键数字/对比一律用本模板的数据类版式（big-num / glass-grid / trend）呈现，不准埋进句子里。
- 玻璃感靠留白与光晕，不靠少字：字数下限由本节把关，别以"玻璃感"为借口交半空页。
