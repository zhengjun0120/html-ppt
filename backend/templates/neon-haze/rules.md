# 深色弥散 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 中文黑体粗标题（h1/h2 已内建字重与柔光），正文 Light 浅紫（lede/nh-d 已内建）；
  数字、时间点与英文标签一律等宽（nh-n / nh-kicker / nh-stat-v / nh-tl-t 已内建 JetBrains Mono 栈）。
- 英文点缀一律全大写 + 宽字距（nh-kicker 已内建 text-transform），像夜场的播报字幕。
- 语气是「夜场的克制」：写光、色温、人流与动作，不写「炸裂」「燃爆」这类喧哗词——
  氛围靠画面给，文字要冷静。

## 结构纪律（光晕是身份）

- 弥散光斑与渐隐网格住在背景层（模板自动衬底），正文不要手画光斑、不加 backdrop-filter
  毛玻璃——要的是弥散的光，不是磨砂的玻璃。
- 霓虹三色分工，不混用：青绿=题签、编号、时间点、青绿药丸；品红=强调词、光点、品红药丸
  与行动钮；电光蓝只做氛围光，不写文字。
- 标题柔光已内建（text-shadow），不要再给文字叠新发光；正文长句一律近白/浅紫，不上霓虹色。
- 卡只有一种：半透明夜幕底 + 细描边（nh-card）。禁纯白卡、禁大圆角气泡滥用（本模板圆角克制）。

## 禁令

- 禁 emoji；禁浅色底与白底；禁衬线、手写体；禁写实照片位与玻璃拟态。
- 禁把光斑做得太满太乱：一页的强调词（nh-hl）至多 2 个，品红只点亮一两个词。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的空间与动作）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，等宽大数字是主视觉，不准埋进句子里。

## 节奏

- 页序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是夜场的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
