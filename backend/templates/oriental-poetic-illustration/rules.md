# 东方意境插画 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律楷书气质（h1/h2 已内建楷体栈 + 大字距），正文宋体宽行距（行高 1.8-2.0）；小字标签用无衬线（oi-kicker / oi-pill / deck-footer 已内建）。不要引入黑体粗标题、圆体或手写花体。
- 语气要「空山气」：写呼吸、身体、时辰与具体动作（像"数到六，念头来了，不追"），不写抽象大词。
- 数字与英文用无衬线细体呈现（模板已内建），不要给数字加楷体。

## 结构纪律（墨竹绿与朱红是身份）

- 墨竹绿只允许出现在五处：编号圈（oi-n / oi-tl-dot）、关键数据（oi-stat-v / oi-tl-t）、要点药丸（oi-pill-accent）、行动钮（oi-btn）。禁把墨竹绿用于大标题、大面积色块或整卡底色。
- 朱红只允许两处：印章 oi-seal、题签墨点（oi-kicker 自带）。一页至多一枚印，全份 deck 至多三枚。
- 卡只有一种：月白半透明底 + 淡竹青细描边（oi-card）。禁硬阴影、禁深色底卡、禁圆角大卡。
- 留白即构图：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。
- 竖排 oi-vert 只放留白处，一页至多一条，内容是诗句或四字短语，禁放正文数据。

## 禁令

- 禁 emoji；禁荧光色、金属质感、霓虹光、玻璃拟态。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格与贴图堆叠；对比类内容用 split 或 keynotes 的三卡承载。
- 禁卡通插画与赛博元素混搭；月轮竹影由模板自动衬底，正文不要再画第二重装饰。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 卷轴顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是题诗的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
