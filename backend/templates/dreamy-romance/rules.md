# 梦幻浪漫·治愈系 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律宋体抒情气质（h1/h2 已内建宋体栈 + 柔光投影），正文细无衬线宽行距；小字标签用无衬线（dm-kicker / dm-pill / deck-footer 已内建）。不要引入黑体粗标题、圆体或书法体。
- 语气要「有体温的细小」：写气味、温度、动作与人话（像"奶云要厚，心要软"），不写抽象大词。
- 数字与英文用无衬线呈现（dm-stat-v / dm-tl-t 已内建），不要给数字加宋体。

## 结构纪律（金粉是身份）

- 香槟金只允许出现在三处：编号金环 dm-n / dm-tl-dot、题签星点（dm-kicker 自带）、行动钮渐变（dm-btn）。禁把金色用于大面积色块或整卡底色。
- 樱粉只做关键数据（dm-stat-v）、时间点（dm-tl-t）与樱粉题签（dm-pill-accent）；正文一律深紫灰实色。
- 卡只有一种：大圆角半透明白 + 柔光阴影（dm-card）。禁深色背景、禁硬阴影、禁 backdrop-filter 玻璃拟态——上游 SKILL 明令「不能用白色背景」，底色始终是雾紫奶油调。
- 爱心 dm-heart 是唯一的具象符号，一页至多一枚，只放留白处或同排点缀，禁当列表符号。

## 禁令

- 禁 emoji；禁高饱和、霓虹、刺眼色；禁深暗背景。
- 禁锋利几何与硬朗工业元素（直角卡、粗黑描边、金属渐变）。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁把页面塞满：治愈系一页最多两组内容块 + 页脚，诗意来自留白。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 开业叙事保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是抒情段的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
