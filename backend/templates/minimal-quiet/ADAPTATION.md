# minimal-quiet 入库适配记录

来源：taste-skill/skills/minimalist-skill（「Premium Utilitarian Minimalism & Editorial UI」，MIT）。
与既有模板不同，本模板没有上游 HTML 可搬——**全部文件从零手写**，只借鉴该 skill 的设计思想。
入库日期：2026-09-18。

## 从来源 skill 借鉴的设计思想（非代码）

1. 暖骨白画布 #F7F6F3 + 白卡 + 1px #EAEAEA 结构线；正文炭黑 #2F3437、次级灰，禁纯黑。
2. 编辑风衬线大标题、tight tracking（-0.02 ~ -0.04em）；项目自托管字体没有衬线，按计划走 Georgia/宋体系统回退。
3. 「洗过的粉彩」色卡 + 深字成对（淡红 #FDEBEC/#9F2F2D、淡蓝 #E1F3FE/#1F6C9F、淡绿 #EDF3EC/#346538、淡黄 #FBF3DB/#956400），颜色只作语义点缀。
4. 阴影如有必须极散（<0.05 透明度）；禁渐变、禁大容器药丸、禁 emoji、禁 AI 腔——与项目 lint 词表同源。

## 翻译成幻灯片时的本地决策

1. **场景选「个人季度复盘 / OKR 回顾」**：极简编辑风的最佳载体是「对自己汇报」的安静文档，而非营销页；demo 全部用可查证的个人数据（92 分 / 218 km / 7 本 / 64 篇）。
2. **版式 9 个、指纹 6 种**（hero / table / cards / chart / split / quote）：case-split 的右侧不用代码终端，改成 mono 日志摘录面板（mq-panel）——复盘场景里「工作日志」比代码更真实，同时保住 split 指纹。
3. **数字用衬线炭黑而非强调色**（mq-stat-v）：安静模板里数字是主角靠字号与衬线，不靠颜色喊。
4. **deck-footer 每页保留**：mono 页脚 + 页码既是编辑风家具，也让每页填充收底。
5. 变体只换强调墨 + 色卡对（雾蓝 / 陶红 / 苔绿），底盘与字阶不动，保证变体间对比度一致（三种墨色对 --bg 均 ≥4.8:1）。
6. 字号下限：正文/说明 18px+、半内容 17px（口径注、摘录）、装饰小字 15px（胶囊、kicker、页脚）、无 <14px。
