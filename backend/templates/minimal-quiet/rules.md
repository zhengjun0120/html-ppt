# minimal-quiet · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题走衬线栈（Playfair Display → Georgia → 宋体系统回退），只给 h1/h2 和大数字用；中文正文用默认无衬线，不要给正文指定衬线。
- kicker、页脚、日期、周期、编号等「记录性小字」一律 `<span class="mono">` 或带 mono 类的胶囊，这是本模板的编辑气质来源。
- 强调色只能成对使用：粉彩色卡 + 它的深字（如 淡绿 #EDF3EC 配 #346538）。不准单取深字当大底色，不准给大面积区块上色。

## 安静纪律（本模板的身份）

- 颜色是稀缺资源：一页最多出现 2-3 处粉彩，其余一律炭黑/灰阶。没有语义的颜色宁可不上。
- 卡片一律 1px 细线 + 圆角 ≤12px + 24-40px 内边距；禁渐变、禁重投影、禁给大容器用药丸形圆角。
- 正文永远炭黑（--text-1 #2F3437 系），不写纯黑；次级信息用 --text-2，不许再深再浅自造灰阶。
- 章节幕的描边大数字（mq-ghost）是全模板唯一的装饰大字，一页最多一个。

## 禁令

- 禁 emoji；对勾、箭头等排版符号也少用，优先用文字胶囊表达结论（「达成」「延期」「超额」）。
- 禁 AI 腔（词表与项目 lint 同源：口号式动词、营销形容词一律换成具体动作与事实）；复盘语言要像工作日志，不像发布会。
- 禁编造精确数字：个人数据必须给得出口径与来源；没有就用区间，并在页尾标「估算」。
- 禁一页多个破折号「——」；编辑风靠分号、冒号和句号断句。

## 密度

- 每页可见文字 100-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-45 字：一句论断 + 一句展开，句号结尾的完整句，不写半截句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留，它同时是填充的收底。
- **数字纪律**：关键数字/对比一律 metrics、okr-table 呈现（一张卡一个数 + 口径），不准埋进句子里。

## 节奏

- 复盘骨架顺序保持完整：cover → agenda → 内容（okr-table / metrics / case-split）→ reflections → quote-note → closing。
- 同一版式最多连用 2 页；quote-note 全份 deck 出现 1 次即可，它是「压轴句」不是普通内容页。
- divider 在 8 页以上的 deck 至少出现 1 次；metrics 与 case-split 之间至少隔一个非数据页。
