# 扁豆紫蜜陀僧 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律楷宋气质（h1/h2 已内建宋体楷体栈），正文宋体宽行距；小字标签用无衬线
  （aa-kicker / aa-pill / deck-footer 已内建）。不要引入黑体粗标题、圆体或花体。
- 语气要「有体温的具体」：写时候、气味、动作与人话（像"前调是落日，尾调是安睡"），
  不写抽象大词，也不说"治疗""功效"，只说"适合"。
- 数字与英文用无衬线呈现（模板已内建），不要给数字加宋体。

## 结构纪律（暮色深褐是身份）

- 暮色深褐只允许出现在四处：印章 aa-seal、方章编号（aa-n / aa-tl-dot）、暮色签
  aa-pill-accent、按钮 aa-btn；上面只放奶白字。禁把深褐用于大面积色块或整卡底色。
- 正文一律深琥珀墨（--ink 系）直接落在暮色渐变上；长内容优先进半透米白卡 aa-card。
  琥珀左线卡（aa-card-line）仅限 split 右列。禁硬阴影、禁直角锐利大卡。
- 落日光晕、萤光与水面是自动衬底：正文不要再画太阳、星星或波浪；竖排 aa-vert 只放
  留白处，一页至多一条，内容是短语或四字句，禁放正文数据。
- 留白即意境：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。

## 禁令

- 禁 emoji；禁冷色（蓝绿及冷调紫）、荧光色、金属渐变、玻璃拟态、商业 KPI 卡片。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 暮色顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是黄昏的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
