# 明黄钴蓝 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律无衬线超粗（h1/h2 已内建 900 字重、行紧字密），正文无衬线 Regular；小字标签同为无衬线（cs-kicker / cs-pill / deck-footer 已内建）。不要引入衬线标题、手写体或圆体。
- 语气要「有数据的行动感」：写榜单、案例、数字与人话（像"18 个案例里 11 个改了标题"），可以比安静系模板更有能量，但禁口号式空话。
- 中英混排允许少量英文短标签（kicker、贴纸），正文以中文为主；数字用无衬线呈现（模板已内建）。

## 结构纪律（撞色是身份）

- 钴蓝实底只允许出现在六处：题签 cs-kicker、徽章 cs-badge、数据块 cs-cell、时间线圆点 cs-tl-dot、实心药丸 cs-pill-accent、按钮 cs-btn。禁把钴蓝铺成整页底色（letterbox 底色恒为明黄，整页蓝底会翻页跳色）。
- 撞色纪律：黄底配蓝字、蓝底配黄字或白字；禁蓝底蓝字、黄底黄字、低对比灰字。
- 卡只有一种：白底 + 钴蓝硬描边 + 硬偏移阴影（cs-card）。禁柔光、毛玻璃、模糊阴影、大圆角软糖卡。
- 每页至多一个旋转元素（cs-tag 或旋转摆放的 cs-badge），多则散；正文数据不进旋转元素。
- 留白即节奏：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉撞色的呼吸感。

## 禁令

- 禁 emoji；禁低饱和灰调、金属渐变、玻璃拟态、柔光阴影。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，大数字进 cs-cell（蓝底黄字），不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是整场的「压轴金句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
