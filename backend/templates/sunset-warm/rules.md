# 日落暖 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文一律友好无衬线、字重中等（h1/h2 已内建）；引文可用衬线大字（su-quote 已内建 Georgia/宋体栈）；小字标签用等宽大写签（su-kicker / su-pill / deck-footer 已内建）。不要引入正式的印刷衬线正文或手写花体。
- 语气要「一切都很美好」的具体：写光线、时刻、温度与人话（像"誓言提前日落两分钟开始"），不写抽象抒情大词。
- 数字与英文用无衬线呈现（模板已内建），等宽字只用于题签小签。

## 结构纪律（暖而不压迫）

- 亮橙 #F97316 与金黄 #FBBF24 只做光泽：题签圆点、太阳印 su-badge、金环圆号 su-n / su-tl-dot、数字块上边线 su-stat 顶线、accent 药丸软底。禁把亮橙铺成整页色块或整卡底色。
- 白卡只有两种：内容卡 su-card、数字块 su-stat——白底浮在暖色上、橘色柔和描边。禁硬黑阴影、禁直角卡。
- 深焦糖 #7C2D12 是标题与页脚的骨架色；正文焦橙 #9A3412。禁用纯黑。
- 光环 su-halo 只在 quote 页留白处一轮，装饰不写字；一页最多两组内容块 + 页脚。

## 禁令

- 禁冷色调与暗色背景——日落暖里不许出现夜色。
- 禁正式排版（对齐的表格线、公文式编号）——这是明信片，不是年报。
- 禁让暖色变成压迫感：渐变保持轻盈，橙只做光泽与描边，不做大面积实底。
- 禁 emoji；禁荧光色、金属渐变、玻璃拟态。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的时刻、光线与动作）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是黄昏里的「压轴一轮」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
