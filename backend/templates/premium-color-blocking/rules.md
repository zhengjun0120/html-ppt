# 高级撞色 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律超粗收紧的无衬线（h1/h2 已内建 900 字重与负字距），正文 400-500 字重保持行距 1.6 以上；小字标签粗体大写（pc-kicker / pc-pill / deck-footer 已内建）。不要引入衬线正文、花体或细弱字重。
- 语气要有态度但克制：写决定、比例与边界（像「配色不超过三种」），不写叫卖式感叹。
- 数字是画面的一部分：大数字用 900 字重橙色，禁止给数字加描边或阴影。

## 结构纪律（撞色是身份）

- 全页主色不超过三种：珊瑚橙 #FF6B47、深墨蓝 #1B2A4A、奶白纸底 #F4EFE6；柠黄只用于 pc-kicker 标签。禁出现第四种色相。
- 色块只有两种：锐利白卡（2px 墨蓝粗边、零圆角）与墨蓝实色块（pc-card-ink）。一页至多一块实色块；禁渐变、禁毛玻璃、禁拟物阴影。
- 分隔用粗实线（3px 以上，pc-item / pc-step 自带），不用发丝线；留白要狠，一页最多两组内容块 + 页脚。
- 斜切是唯一的破格手法（pc-slash），一页至多一处；不再叠加旋转或其他变形。

## 禁令

- 禁 emoji；禁柔粉、马卡龙、莫兰迪等低饱和温柔色——它们与撞色气质相反。
- 禁 AI 腔（空洞口号）；态度来自具体的比例、材质与决定。
- 禁编造精确数字：企划数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；比较类内容用 keynotes 三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 大片顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是宣言的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；色块页与留白页穿插，不要连排实色块。
