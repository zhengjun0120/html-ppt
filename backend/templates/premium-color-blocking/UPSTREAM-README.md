# premium-color-blocking（高级撞色）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/premium-color-blocking`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：暖橙 × 冷墨强对峙——珊瑚橙 #FF6B47、琥珀橘 #F5A623 对深墨蓝 #1B2A4A、午夜青 #0F3B4C；
  奶白 #F4EFE6 / 象牙 #EDE4D3 做中性底；柠黄 #F4D35E / 正红 #E63946 只做点睛。
  比例约暖 45% / 冷 30% / 中性 25%。
- 排版：粗壮几何无衬线，字重 800-900，字距收紧约 -2%；正文 400 字重行高 1.6。
- 装饰：平涂色块、斜向切分、几何锚点（圆/半圆/粗线条），丝网印刷般的锐利边缘。
- 布局：网格严谨但敢于破格，模块之间用粗实线或色带分隔；整页不超过 5 个层级。
- 禁忌：超过三种主色、柔粉马卡龙、渐变背景、毛玻璃、拟物阴影、3D、元素挤满画面。

## 转换说明

- 上游预览页的核心构图（左上斜切橙块 + 右下墨蓝块 + 柠黄细带 + 圆形锚点）移植为模板语言：
  大色块保留给 pc-card-ink / pc-pill-accent / pc-btn 三个实色件，左缘 14px 双色书脊与右上描边圆
  做成 ambient 层（.slide::before/::after，z-index:-1），每页自动衬底、不进骨架。
- cover 的柠黄标签（pc-kicker）沿用上游 kicker 的「黄底墨字」做法，全模板柠黄只出现在这一处。
- 正文/说明统一蓝灰 #46557A：纯墨蓝做正文太沉，蓝灰在对峙色之间更耐看。
- 字体栈：Inter + Noto Sans SC，标题 900 字重 -0.03em；不新增 webfont 文件。
