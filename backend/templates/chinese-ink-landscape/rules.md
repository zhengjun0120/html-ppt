# 中式水墨意境·山水 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律宋体加粗大字距气质（h1/h2 已内建宋体栈），副题与竖排短句用楷体（cl-vert / cl-seal 已内建），小字标签用无衬线（cl-kicker / cl-pill / deck-footer 已内建）。不要引入黑体粗标题、手写花体或圆体。
- 语气要「登高望远的具体」：写山势、云雾、步道与人的动作（像"云海多在雨后初晴的清晨"），不写抽象大词。
- 数字与英文用无衬线细体呈现（模板已内建），不要给数字加宋体楷体。

## 结构纪律（朱砂与青黛是身份）

- 朱砂只允许出现在三处：印章 cl-seal、题签细线（cl-kicker 自带）、关键数据（cl-stat-v / cl-tl-t / cl-pill-accent / cl-vert-accent）。禁把朱砂用于大标题、大面积色块或整卡底色。
- 青黛蓝只允许出现在山棱线（cl-ridge）与数字块顶线（cl-stat）；远山灰蓝与暖沙米只出现在页底山峦 ambient 与色卡（cl-swatches），不手动画。
- 卡只有一种：宣纸米半透明底 + 细线框（cl-card）。禁硬阴影、禁纯白死底、禁圆角大卡、禁金属质感与复杂渐变。
- 留白即云雾：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。
- 页底山峦约 310px 高：正文与页脚不与山峦抢位，卡片别压到画布最底边。
- 竖排 cl-vert 只放留白处，一页至多一条；色卡 cl-swatches 全份 deck 至多一次，放 cover 或 closing。

## 禁令

- 禁 emoji；禁高饱和荧光、赛博霓虹、金属质感、复杂渐变、玻璃拟态。
- 禁卡通或工业风混搭；禁深色页——这份模板的底永远是云雾白与宣纸米。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 行山顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是登顶后的「压轴一句诗」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
