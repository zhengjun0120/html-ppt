# 瑞士国际主义 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律细体大字（h1/h2 已内建 200 字重、负字距），小字加粗（h4 700）；正文 17-22px
  常规字重。主标题与正文的字号比例保持 8:1 量级——越大越细、越小越粗。
- 标签、索引、出处、页脚一律等宽全大写（si-meta / si-i / si-tag / si-src / deck-footer
  已内建），禁用等宽字写中文正文句子。
- 语言冷静精确：写数字、口径、结构与判断，不写形容词堆叠；每个论断能被下一页的数据接住。

## 结构纪律（IKB 蓝是唯一强调色）

- 蓝色只允许出现在：元信息方块 si-square、文字强调 si-accent、焦点格 si-metric-accent /
  si-cell-accent、方角标签 si-tag-accent、行动钮 si-btn。一页蓝色元素不超过两处。
- 全部直角：禁圆角、禁阴影、禁渐变、禁圆点与装饰图案；分隔只允许 hairline 细线与
  黑缝拼格（si-mesh）。
- 一切左对齐；并列三格只允许一格做蓝色焦点（骨架里固定为第二格）。
- 一页最多两组内容块 + 页脚；留白不加装饰补足，结构本身就是视觉。

## 禁令

- 禁衬线字体、禁手写体；禁混用第二种强调色。
- 禁粗重标题（标题 200 字重已定，勿覆盖加粗）、禁无约束的大字号。
- 禁 emoji、禁 AI 腔；禁编造精确数字——数据必须给口径与来源（si-src 写在页尾）。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比内容用 keynotes 三格或 split 承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 格内说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）与 si-meta 每页都保留。
- **数字纪律**：关键数据一律 metrics 或 cover 的 KPI 条呈现，数值 ≤6 字符，
  口径与来源写 si-src，不准埋进句子里。

## 节奏

- 报告顺序保持完整：cover → contents → metrics → divider → keynotes / split →
  moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，是宣言的压轴一格。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与论点页穿插，不要连排。
