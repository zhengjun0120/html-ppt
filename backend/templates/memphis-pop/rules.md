# 孟菲斯波普 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线：h1/h2 用 900 字重（模板已内建，大字重本身就是装饰），正文 400，卡说明用完整句。
- 语气年轻、直接、带态度，可以有一点夸张，但「反叛」要落在具体的物与做法上，不写空口号。
- 数字用等宽数字呈现（模板已内建 tabular-nums），大数字只留给 metrics 页。

## 结构纪律（撞色是身份）

- 颜色只有三个主角：琥珀黄 #F59E0B、薰衣草紫 #8B5CF6、靛蓝 #818CF8，加墨蓝黑 #0F172A 压阵。
- 粗黑描边 + 硬投影只属于 mp-card / mp-stat / mp-btn；正文与页脚保持干净，不加描边。
- 黑底题签 mp-kicker 每页至多一枚；几何碎屑由模板自动衬底，骨架里不要再手画形状。
- 一页最多两组内容块 + 页脚；热闹来自装饰与色彩，不来自加行数。

## 禁令

- 禁 emoji；禁三主角之外的荧光色文字；禁渐变文字与玻璃拟态。
- 禁把整页铺成高饱和大色块——底色是浅三色渐变，饱和色只出现在卡、签、按钮与投影上。
- 禁 AI 腔与营销形容词堆砌；禁无口径的精确数字（没有来源就写区间或量级）。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是全场的「安可」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
