# 融资路演 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与数字一律 Inter 800/900（h1/h2 已内建），正文精练；等宽字（pv-kicker / pv-round /
  pv-tag / pv-src / deck-footer 已内建）只做元数据、标签与口径，不要用等宽字写正文句子。
- 语气要「投资人的问题清单」：每页回答一个具体问题（市场多大、增长多快、凭什么、钱去哪），
  不写口号与营销形容词；每页文字不超过三行主体。
- 中英文混排时，标签里的英文全大写（TRACTION / THE ASK），正文句子保持中文自然语序。

## 结构纪律（紫罗兰是身份）

- 紫罗兰渐变只允许出现在四处：封面侧板 pv-panel、编号块 pv-n、实心标签 pv-tag-solid、
  行动钮 pv-btn。标题与数字永远深靛 #1E1B4B，禁把渐变用于整页背景或正文卡底。
- 卡只有一种：白底 .92 + 极淡紫描边（pv-card）。禁硬边框、禁大面积色块卡、禁深底卡。
- 等宽小节标签（pv-kicker）每页最多一条，放页首；标签（pv-tag）一排不超过 4 个。
- 大留白是核心：一页只传达一个关键信息，不要往卡里塞第四行小字。

## 禁令

- 禁 emoji；禁超过三种颜色（深靛 / 靛蓝 / 紫罗兰系之外的颜色一律不用）。
- 密集内容与小字是本风格的天敌：禁高密度表格、禁长段落（lede 之外正文 ≤2 句）。
- 禁编造精确数字：核心指标必须给口径与来源（pv-src 写在页尾），没有来源就写区间或标「估算」。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁让装饰分散对数字的注意力：渐变只出现在身份四处，其余留白。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 cover 的 traction 区呈现，数值 ≤6 字符，
  不准把长数字埋进句子里；增长趋势用 pv-bars 柱阵表达，不画折线。

## 节奏

- 路演顺序保持完整：cover → contents → metrics → divider → keynotes / split →
  moments / quote → closing（The Ask 压轴）。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，放在数据之后、要钱之前「点火」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与论点页穿插，不要连排。
