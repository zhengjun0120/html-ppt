# course-module · 质量规则

- 教学结构灵活用：概念（concept）、数字（stat）、时间线（timeline）、示例（example）、练习（exercise）、自测（check）按内容需要排；同一版式最多连用 2 页。
- **数字是主视觉**：关键数字、占比、对比一律用 stat/timeline 版式呈现（一张卡一个数 + 口径），不准把数字埋进正文句子里。
- **每页要有下半区**：骨架从上到下要占满画布——量测会检查填充率，大面积留白的页会被打回。
- concept-box 里放定义和解释（一句话 + 一句展开），callout 放易错点/关键点，别把定义写成一整段。
- mcq 的正确项用 correct 类标注（课堂揭晓态）；干扰项要"似是而非"，不出送分题。
- 代码块里的 HTML 必须转义（&lt; &gt; &amp;），行数 8-16。
- 侧栏（sidebar）是模板骨架的一部分，照抄结构、替换 {{占位符}}，页面内容不写进侧栏外面。
- 禁 emoji；每页正文文字 100-220 字。
