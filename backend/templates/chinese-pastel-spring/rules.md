# 春日嫩柳 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题宋体加粗、次级标题与卡题楷体（h1/h2/h4 已内建），正文宋体深棕宽行距；
  小字标签用无衬线（ps-kicker / ps-pill / deck-footer 已内建）。不要引入黑体粗大标题、
  手写花体或圆体。
- 数字用现代无衬线细体（ps-stat-v 已内建），形成传统与现代对比；不要给数字加楷体。
- 语气温柔但有具体：写节气、颜色、动作与人话（像「三月里沿苏堤走了两趟」），
  不写「焕新升级」「惊艳上市」这类营销形容词。

## 结构纪律（柔色是身份）

- 嫩柳绿、柳芽黄绿、桃花粉只允许出现在：实色小色卡（ps-chip-green / ps-chip-bud /
  ps-chip-pink，keynotes 专用，一页至多一组）、圆点编号（ps-n / ps-tl-dot，配色由
  nth-child 自动轮换，不要手工改）、数据顶线（ps-stat）与页首渐变带（模板自动衬底）。
- 朱砂只允许四处：印章 ps-seal、题签短线（ps-kicker 自带）、关键数据
  （ps-stat-v / ps-tl-t）、强调药丸（ps-pill-accent）。淡金只做第三条数据顶线点缀。
- 卡只有两种：宣纸卡（ps-card）与左竖线暖卡（ps-card-line，仅限 split 右列）。
  禁硬阴影、禁纯白死底、禁大圆角、禁深色卡底。
- 右上桃枝与页首色带是模板自动衬底，正文不要画花、不要再叠装饰。

## 禁令

- 禁 emoji；禁高饱和荧光、禁赛博霓虹、禁硬朗几何、禁锋利金属质感、禁沉重暗色背景。
- 禁过度装饰：一页除模板自带的桃枝与色带外，不再加任何花纹、边框或角标。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 keynotes 三色卡或 split 承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；
  页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 发布顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是全篇的定调一笔。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
