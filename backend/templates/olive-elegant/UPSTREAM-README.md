# olive-elegant（橄榄奶白·高级稳重）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的
`resources/styles/olive-elegant`（Apache-2.0 License，其 NOTICE 要求保留归属，
本文件即归属声明）。页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：深橄榄绿 #4A5D34 主色（低饱和低明度）作大色块与背景，奶白绿 #E5E0D0 作对位与
  文字底；暖灰 #9A9488、深棕 #3A3326 作正文，金色 #B89B5E 偶尔做高级强调。
- 意象：古典纹样（回纹、卷草、菱形连续图案）、植物线稿（橄榄枝、月桂叶）、金色细线
  分隔与边框、半透明色块卡片。
- 排版：标题衬线（思源宋体气质、字重中等偏粗），正文现代无衬线 Light、行距宽；
  可混排英文衬线斜体做装饰标题。
- 布局：对称、稳重、有仪式感；卡片直角或小圆角 + 金色细边框，古典书页感。
- 动画：ease-in-out 0.8–1.3s，整体元素淡入，不做逐字 reveal、不做弹跳。
- 禁忌：高饱和霓虹荧光、硬朗现代几何、轻浮弹跳动画、商业 KPI 卡密集排布、塞满画面。

## 转换说明

- 上游只有一张 1600×900 的单页预览（左橄榄色块 + 右米白内容的双栏封面）；本模板按
  本仓库 deck-v2 契约重建为 9 版式骨架（cover/contents/keynotes/split/metrics/
  quote/divider/moments/closing）。
- 按任务的深色·奢华方向转换：整页改为橄榄绿渐变（#42522F → #33402A → #232D1A），
  渐变中段 #33402A 兼作 letterbox 底色（--bg），翻页不跳；文字反转为奶白系
  （#EDE7D6 主字，小字 #B3AA94 对底 ≥4.5:1），上游 #4A5D34 保留为卡片的半透明底色。
- 金色细线是唯一装饰语言：全页金细框（.slide::before）+ 页角橄榄枝线稿与菱形点缀
  （.slide::after，data-URI SVG，z-index:-1）每页自动衬底；题签沿用上游的「◆」菱形。
- 字体栈：标题 Georgia + 宋体（衬线，沿用上游气质），正文 Inter/Noto Sans SC Light
  （无衬线细体），英文题记衬线斜体；不新增 webfont 文件。
