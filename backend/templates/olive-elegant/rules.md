# 橄榄奶白·高级稳重 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题用衬线（h1/h2/h4/oe-quote 已内建 Georgia+宋体栈），正文用无衬线细体宽行距（lede 已内建 Light），小字标签与页脚无衬线（oe-kicker / oe-pill / deck-footer 已内建）。不要引入无衬线粗黑大标题、手写体或圆体——衬线标题 + 细体正文是古典杂志的骨架。
- 英文题记 oe-en 用衬线斜体全大写，一页至多一条，只放在留白处；它是装饰，不承载信息。
- 语气要「稳」：写产地、树龄、工艺与时间（像「橄榄一离枝，时钟就开始走」），不写营销形容词与口号。
- 数字与英文用无衬线呈现（oe-stat-u / oe-tl-t / deck-footer 已内建），规格与年份写全。

## 结构纪律（金线是身份，奶白是唯一亮色）

- 金色只允许出现在细处：oe-kicker 菱形、oe-rule 金线、oe-n / oe-tl-dot 描边、oe-btn 描边、oe-stat-u / oe-stat-l 单位与指标名、oe-pill-accent。禁大面积金色、禁金色大标题、禁金色底卡。
- 卡只有一种：半透明橄榄色块 + 金细边（oe-card）。禁白色卡、禁彩色底卡、禁大圆角卡、禁硬阴影。
- 页面四周的金色细框与页角橄榄枝是模板自动衬底的 ambient 层，骨架与正文都不要重画边框或枝叶。
- 奶白是唯一的亮色面：标题、正文、大数字都用奶白系（--ink/--ink-2）；页面底部是橄榄渐变，禁深色文字（对比度不达标会被门禁打回）。
- 对称、稳重、有仪式感：一页最多两组内容块 + 页脚；不要塞满，留白克制但精致。

## 禁令

- 禁 emoji；禁高饱和、霓虹、荧光、硬朗现代几何、玻璃拟态。
- 禁 AI 腔：营销形容词换成具体的产地、树龄、工艺与时间细节。
- 禁编造精确数字：酸度、产量、面积必须给口径与来源（写在页尾）；没有权威来源就写区间或「以批次检测单为准」。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁商业 KPI 卡密集排布；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：酸度、产量、面积、规格一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 发布会顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是发布会的「产地题词」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
