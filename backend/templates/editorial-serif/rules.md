# 杂志衬线 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文一律衬线（全模板 Georgia/宋体栈，正文连段落都是衬线——这是与「杂志大字」最大的分野）；小字标签与图注用等宽（es-tag / es-src / deck-footer 已内建），斜体英文只做副题与注记。不要用无衬线做标题，不要加粗正文段落。
- 语气要「编辑部」：写词、腔调与读法（像"把祖母的词汇表原样搬进小说"），每段都像被编辑过。不写通稿腔。
- 数字用衬线大字呈现（es-stat-v 已内建），来源与出处用等宽小字。

## 结构纪律（深橙是红笔）

- 全页只用暖色系：深褐 #431407、焦棕 #7C2D12、深橙 #EA580C。禁冷色调、禁青蓝紫。
- 深橙只出现在六处：细杠与短线（es-tag / es-rule 自带）、首字下沉（es-drop）、橙圈序号（es-n / es-tl-dot）、关键数据（es-stat-v）、引言左线（es-quote-block 自带）、药丸圈点（es-pill-accent）。禁橙色正文、禁大面积橙色色块。
- 卡只有一种：暖白 rgba(255,250,245,.9) + 极淡棕描边（es-card）。禁重阴影、禁冷白死底。
- 首字下沉 es-drop 全份最多两处，只套在 lede 导语的第一个字上；斜体英文 es-en 一页至多一行。

## 禁令

- 禁 emoji；禁冷色调、禁无衬线标题、禁密集排版压缩文字的呼吸。
- 禁 AI 腔；导读的文气来自具体的词、腔调与读法，不写「赋能」「破圈」。
- 禁编造精确数字：刊物数据必须给口径与来源（写在页尾），没有来源就写区间或期数。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；多角度导读用 keynotes 三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：刊物体量与流程数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 刊物顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是卷首语的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
