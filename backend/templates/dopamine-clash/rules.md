# 多巴胺活力撞色 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律特粗无衬线（h1/h2 已内建 900 字重），正文细无衬线保持透气；数字与标签用等宽字体（dc-kicker / dc-n / dc-stat-v / dc-tl-t 已内建 JetBrains Mono）。不要引入衬线、书法体或手写体。
- 语气要「直给但具体」：写动作、数字、场合与人话（像"快乐不要克制，但配色要有配比"），口号最多出现在标题，正文必须落地。
- 数字用等宽大号呈现，禁给数字加渐变或描边。

## 结构纪律（撞色有配比，对比度合规）

- 三色配比固定：淡紫与亮绿是大面积打底色，玫粉只做小面积焦点（硬阴影、贴纸、时间点、菱形糖）。禁三色等分平铺，禁留白少于三成。
- **对比度铁律**：淡紫/亮绿块上只压近黑文字；玫粉上的文字一律近黑；白字只允许出现在黑底（dc-kicker / dc-btn）。正文与卡内文字一律近黑或灰紫收暗色（骨架内联色已写好，照抄）。
- 卡与钮只有一种画法：黑描边 + 同色系硬阴影（dc-card / dc-stat / dc-btn）。禁软阴影、禁圆角小于 12px 的锐利卡、禁无描边裸色块卡。
- 菱形糖 dc-diamond 一页一颗；旋转贴纸 dc-stamp 只在封面用。装饰不许再叠加。

## 禁令

- 禁 emoji 表情符号（几何装饰由模板 ambient 层提供，骨架不画）。
- 禁低饱和灰蒙、性冷淡配色；禁写实照片位、复杂 mesh 渐变。
- 禁衬线字体、书法字体；禁对称四平八稳的构图（允许且鼓励轻微旋转与错位）。
- 禁 AI 腔：口号只准当标题，正文换成具体动作与场景；禁空泛形容词。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 企划顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是高亮时刻的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
