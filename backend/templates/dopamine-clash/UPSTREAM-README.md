# dopamine-clash（多巴胺活力撞色）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/dopamine-clash`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色三件套：淡紫 `#A299F4` 大面积基底，亮绿 `#CCEC6D` 对位色块，玫粉 `#F454AE` 视觉焦点；
  纯白 `#FFFFFF` 留白与文字、纯黑 `#000000` 偶尔做强调。高饱和但比例克制，避免刺眼。
- 意象：菱形、圆角矩形、半圆、波浪条等几何；圆点矩阵、棋盘格节奏纹理；色块切割画面。
- 排版：粗壮无衬线（思源黑体 Bold / 阿里巴巴普惠体 Heavy），字号大字重重，常压在色块
  边缘做反白；正文细无衬线；等宽字体（JetBrains Mono）做数字与标签强化潮流感。
- 布局：大色块切割版面，标题压在撞色交界处；卡片大圆角色块填充，「标签 + 数字」胶囊。
- 禁忌：低饱和灰蒙、性冷淡；写实照片、复杂渐变 mesh；衬线与书法字体；对称四平八稳；
  三色用满不留白。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 上源的「上下大色块 + 波浪条 + 圆点矩阵」改写为 ambient 层：`.slide::before` 的右上玫粉
  圆角、左下淡紫柔角与左上圆点矩阵 SVG，`.slide::after` 的底边绿白粉三色条
  （高 10px，避开页脚）。每页自动衬底（z-index:-1），不进骨架。
- **对比度改造（本模板的核心转换决策）**：上游预览的「白字压淡紫大标题」约 2.5:1，
  不满足 WCAG。本模板改为：淡紫/亮绿块上只压近黑文字（8:1+），玫粉上文字一律近黑
  （6.5:1），白字只出现在黑底（dc-kicker / dc-btn，16:1）；玫粉小字用收暗档
  `#D63B95`（4.1:1，大字号）。活力保住，正文合规。
- 上源的黑色胶囊统计卡转写为「白底黑描边 + 三色轮换硬阴影」的 dc-stat（等宽大数字），
  与 dc-card / dc-btn 统一为同一套 neo-pop 画法。
- 字体栈：'Noto Sans SC'/'Alibaba PuHuiTi' 特粗标题，数字与标签 'JetBrains Mono'；
  不新增 webfont 文件。
