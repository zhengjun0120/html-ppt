感知与控制

三层架构，各自可靠

感知层D-01

96 点三分区

每分区独立成网，单点失效不影响分区读数。点位高度按作物冠层逐月可调。

执行层D-02

双回路执行

水肥一体机与天窗电机走双回路供电，指令回路延迟不超过两秒，故障自动切换。

逻辑层D-03

十分钟巡检

环控程序每十分钟全区巡检一轮，越界即告警到值班手机，夜间不漏检。

管线与执行

走线的三条规矩

管线沿桁架下弦敷设，不占种植面、不挡光照；每条支管在跨端设阀门井，单跨检修不停整棚。桥架与水管分左右，避免结露滴线。

验收标准很简单：任一跨单独泄压检修，其余跨的流量波动不超过一成。

环控逻辑 · 夜间巡检

巡检一轮，越界即动

zone_control.pseudoPSEUDO
# 青畦 3 号温室 · 夜间巡检 v0.3
for zone in [A1, A2, B1, B2]:
    t = sensor(zone, "temp").read()
    h = sensor(zone, "humidity").read()
    if t < 18.0:
        heater(zone).set(ON)        # 保温
    if h > 0.85:
        vent(zone).open(0.5)        # 除湿
    log("patrol", zone, t, h)

每十分钟一轮；连续两轮越界升级为电话告警，值班表见附件。
