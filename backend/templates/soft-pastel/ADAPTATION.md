# soft-pastel 入库适配记录

来源：taste-skill/skills/soft-skill（「Soft Structuralism」氛围原型 + Double-Bezel / Island Button 组件规范，MIT）。
与既有模板不同，本模板没有上游 HTML 可搬——**全部文件从零手写**，只借鉴该 skill 的设计思想。
入库日期：2026-09-18。

## 从来源 skill 借鉴的设计思想（非代码）

1. Soft Structuralism 原型：银灰白底、超大加粗 Grotesk 标题（Inter 800 级、-0.035em）、空气感浮动组件 + 极散环境影（0 32px 64px @ .09）。
2. Double-Bezel（双层表圈）：外壳 = 4% 墨底 + 发丝边 + 8px 内衬 + 2rem 圆角；白芯 = 2rem-8px 同心圆角。幻灯片上表现为 .sp-shell > .sp-core，一切卡片都住在外壳层里。
3. Island Button（按钮即小岛）：全圆角药丸按钮，箭头永不裸放——嵌进按钮右端自己的圆形位（.sp-orb）。
4. 眉标（eyebrow）用药丸徽章而非裸文字；药丸只属于小元素。

## 翻译成幻灯片时的本地决策

1. **场景选「新品上市发布」**：软结构主义的消费气质最贴合「有体温的具体」——demo 用香薰品牌「山雾」第三支香「雨后茶园」，全部数据可查证（预约 1842 人 / 217 份问卷 / 推荐率 86%）。
2. **粉彩比 minimal-quit 高半档饱和**：软粉 #FFD6E0 / 软蓝 #CDE8FF / 软黄 #FFF1B8，各配专属深字（#8E2F4F / #1D5C93 / #7A5A00），药丸是粉彩的唯一载体；强调色莓红 #A93A66 走按钮与圆号。
3. **launch-steps 整块住进一张双壳面板**：既保住 table 指纹，又示范「行分隔线只出现在白芯内部」的结构纪律。
4. **无等宽字体**（fonts 只有 Inter / Noto Sans SC）：数字用 800 字重正体，与极客系模板拉开距离。
5. 变体只换强调色 + 它的软底（莓红 / 鼠尾草 / 蜂蜜），三种强调色对画布对比度均 ≥4.6:1，粉彩药丸三色恒定不动。
6. 字号下限：正文/说明 18px+、药丸 15px（装饰小字档）、页脚 15px、无 <14px；静态幻灯片，来源 skill 的动效规范（spring / 磁吸悬停）不适用，未引入。
