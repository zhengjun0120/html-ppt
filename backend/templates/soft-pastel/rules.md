# soft-pastel · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板只有无衬线：标题 Inter 800 级（中文 Noto Sans SC 加粗），超大、收紧字距；中文正文用默认字体，不要引入衬线或手写体。
- 没有等宽字体位：日期、价格、数字直接用加粗正文字重，不要 `<span class="mono">`。
- 语气要「有体温的具体」：写香气、场景、人话（像雨停之后走进茶园），不写抽象卖点。

## 结构纪律（双层表圈是身份）

- 凡是「卡」必须双层：`.sp-shell`（4% 墨底 + 发丝边 + 8px 内衬 + 32px 圆角）包 `.sp-core`（白芯、24px 圆角）。白卡或 1px 灰边框不准直接裸在银灰底上。
- 允许裸在底上的只有四种东西：超大标题、眉标药丸、粉彩药丸、时间线圆点。
- 阴影只有一种：极散环境影（大 spread、低透明度，已收敛在 --shadow-ambient）；不准再加第二层更重的影子。
- 药丸（999px 全圆角）只用于标签、按钮、圆号这些小元素；大方块内容区永远是 32px 外壳 + 24px 白芯。

## 禁令

- 禁 emoji；箭头只允许按钮 sp-orb 里的「→」。
- 禁 AI 腔（词表与项目 lint 同源：口号式动词、营销形容词一律换成具体的人话与场景）；卖点写成可感的细节。
- 禁编造精确数字：预热与销售数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。

## 密度

- 每页可见文字 100-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-45 字：一句论断 + 一句展开，句号结尾的完整句，不写半截句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：预热 / 销售 / 规模数字一律 warmup-stats 或 launch-timeline 呈现，不准埋进句子里。

## 节奏

- 发布骨架顺序保持完整：cover → launch-steps → warmup-stats → divider → 内容（feature-cards / ritual-split）→ launch-timeline → voice-quote → closing。
- 同一版式最多连用 2 页；voice-quote 全份 deck 出现 1 次，它是用户原声的「压轴证词」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页（warmup-stats / launch-timeline）与内容页穿插，不要连排。
