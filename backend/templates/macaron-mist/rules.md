# 柔雾甜梦 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板圆润无衬线（圆体栈已内建）：标题 700 字重深紫大字，正文 400 字重、行距放宽到近两倍。不要引入衬线大标题、严肃商务黑体或锋利几何体。
- 语气要「甜品店的具体」：写口感、温度、香气、时刻与人话（像"甜得像下午四点的光"），不写抽象大词。
- 数字用圆润无衬线呈现（模板已内建），不要给数字换字体。

## 结构纪律（三色马卡龙分工）

- 薄荷、珊瑚、薰衣草各管一摊，一页之内不混用角色：薄荷深色只落在关键数字（mm-stat-v）与行动钮（mm-btn）；珊瑚只落在题签圆点、时间点（mm-tl-t）与珊瑚题签；薰衣草只落在编号（mm-n）、时间线圆点、药丸与卡描边。
- 标题墨色统一深紫（h1/h2/h4 已内建），正文暖灰；禁用三色做正文文字。
- 卡只有一种：半透奶白大圆角 + 薰衣草细描边 + 柔影（mm-card）。禁深色卡、禁直角卡、禁高饱和大色块。
- keynotes 三卡各配一色题签（薄荷/珊瑚/薰衣草），是三色唯一的并列出场；其余场景强调色只用薄荷（mm-pill-mint）。
- 一页最多两组内容块 + 页脚；柔雾靠背景光晕与留白，不靠塞内容。

## 禁令

- 禁高饱和刺眼色、深暗背景、硬朗几何与锐角。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是甜品手记的「压轴一页」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
