# 治愈手绘水彩 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律圆体绘本气质（h1/h2 已内建圆体栈，色是灰绿而非纯黑）；正文同族宽松行距；小字标签用湖蓝细字（hw-kicker / hw-pill / deck-footer 已内建）。不要引入衬线宋体、黑体粗标题或手写花体。
- 语气要「陪伴感」：写笔、水、纸、动作与人话（像"画坏的那张纸，是学费"），不写抽象大词，不说教。
- 关键短句的情绪靠内容本身，不要靠感叹号堆叠；珊瑚色是唯一的"热"色，省着用。

## 结构纪律（晕染是身份）

- 一切色块都必须"晕开"：模板内的底色一律是径向渐变软边界（hw-n / hw-tl-dot 已内建），不要手写清晰边界色块或硬渐变。
- 湖蓝 #5FA8C9 / 深湖蓝 #3E7C99 是主视觉色：数字、药丸、小签；珊瑚 #E4693F 只做时间点（hw-tl-t）与按钮（hw-btn），一页至多两处；天蓝 #87CEEB 只做晕染浅底。
- 卡只有一种：画纸白 + 铅笔软描边 + 极轻投影（hw-card）。禁硬阴影、禁纯白死底、禁深色边框。
- 留白即呼吸：一页最多两组内容块 + 页脚；竖排 hw-vert 只放留白处，一页至多一条，内容是四字短语或短诗，禁放正文数据。

## 禁令

- 禁 emoji；禁高饱和刺眼色、强渐变、强阴影、尖锐几何与硬朗线条。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格与卡片宫格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 绘本顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是扉页的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
