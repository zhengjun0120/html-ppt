# xhs-post · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。
画布是竖版 810×1080（小红书 3:4）：字号大、字要少，每页只讲一件事。

## 语气与语言

- 小红书体：像闺蜜发消息（"等等先别划走""亲测 7 天"），不写书面腔（"综上所述""首先其次"）。
- 正文禁 AI 腔：禁"在当今快节奏的时代""赋能""干货满满""不仅…更是…"；一句一个画面，句号结尾。
- 标题敢用问句和悬念（"每天只睡 6h 还精神？"），但禁标题党式撒谎——正文要接得住。
- 关键数字（90min、20 分钟、3 杯咖啡）写进 hand-box 的加粗大字里，不准埋进长句。

## emoji 政策（本模板源自 emoji 重度装饰风，边界如下）

- emoji 是版面语言的一部分：big-emoji 位 1 个、hand-box 标题开头 1 个、sticker 内可有 1 个、
  引子（❌/💡/✅）1 个——每页合计不超过 6 个。
- emoji 只出现在词首/装饰位，不准插在句子中间当标点用；ht 话题 tag 内不放 emoji。

## 禁令

- 禁半截句：hand-box 说明 12-45 字，句号结尾的完整句。
- 禁编造亲测数据：「亲测 N 天」「评论区告诉我」可以写，精确到小数的伪数据不行。
- 禁一页塞两个主题：竖版画布小，9 图顺序 cover → hook → pain → truth → step×N → result → cta
  保持完整，每页只走一步。
- 禁在骨架外发明新类名；颜色只走 token（var(--accent) 等），唯一例外是 layouts.md 骨架里已写明的 style。

## 密度

- 每页可见文字 60-150 字（竖版 810 画布，字要少而大）；低于下限会被写入门禁直接拒收。
- 卡片说明 12-45 字：一句论断 + 一句共鸣，句号结尾的完整句，不写半截句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回
  （big-emoji 页靠 sticker 与大字撑满纵向）。
- **数字纪律**：关键数字/对比一律 step / result 的加粗大字呈现，不准埋进句子里。

## 节奏

- step 页可连续出现（1→2→3 正是本模板的节奏），但每页只讲一个步骤；
- truth（aha）恰好 1 页，是 hook 与 step 之间的转折；
- cover → hook → pain → truth → step×N → result → cta 的骨架顺序保持完整，总页数 6-9 页。
