# 薄荷清新 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文一律现代无衬线（h1/h2 已内建 Noto Sans SC 中粗），行距放宽；小字标签用薄荷胶囊（mf-kicker / mf-pill / deck-footer 已内建）。
- h1 里至多一个词换衬线轻字（mf-thin，宋体 Light 灰绿），是全套唯一的「质感点缀」，不要整句都用。
- 语气要「具体的自然」：写原料、肤感、季节与光线（像"上脸两分钟成膜"），不写抽象大词。
- 数字与英文用无衬线呈现（模板已内建），不要给数字加衬线或加粗到失重。

## 结构纪律（薄荷是身份）

- 薄荷青填充只允许三处：题签胶囊 mf-kicker、编号圆角块 mf-n / mf-tl-dot、数据上边线 mf-stat 顶线。苔绿只做关键数据（mf-stat-v / mf-tl-t / mf-pill-accent），深墨绿只做标题与 mf-btn。禁把薄荷铺成整页色块或整卡底色。
- 卡只有一种：半透明白 + 大圆角 + 极轻环境影（mf-card）。禁硬阴影、禁直角卡、禁描边粗框。
- 留白即呼吸：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。
- 蕨叶线稿 mf-fern 只在 quote 页留白处出现，装饰不写字、不加内容。

## 禁令

- 禁 emoji；禁荧光绿、霓虹色、玻璃拟态、金属渐变。
- 禁深暗色背景——这套风格是清晨植物园，不是夜店。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的原料、肤感与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格与 KPI 大屏式堆数；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是叶间的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
