# bauhaus（包豪斯）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/bauhaus`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：深红 #991b1b、海军蓝 #1e3a5f 承重，强调色正红 #dc2626 与皇家蓝 #2563eb；
  背景 linear-gradient(160deg, #fef3c7, #fef9c3 50%, #f0f9ff) 如一张泛黄的画布；
  卡片 rgba(255,255,255,0.94)，边框 rgba(0,0,0,0.3) 的清晰深色描边勾勒几何轮廓。
- 排版：粗壮几何无衬线标题、字重偏重、字间距略宽；正文较细、层级分明；
  文字本身就是几何的一部分，嵌入色块容器之中。
- 布局：圆形、三角形、矩形大胆切分画面空间，原色色块占大面积；不对称制造张力，
  但每个元素都严格对齐到隐形网格；几何是视觉主角，正文密度保持低到中。
- 场景：设计宣言、艺术史叙事、产品美学发布、品牌视觉系统展示。
- 禁忌：复杂渐变或照片级图像、柔和曲线与有机形状、超过三种强调色、装饰抢主角。

## 转换说明

- 原上游预览是一张 3×4 网格的色块拼贴（红、蓝、金、藏青、白格 + 藏青 4px 分隔）；
  本模板按本仓库 deck-v2 契约重建为 9 版式骨架
  （cover/contents/keynotes/split/metrics/quote/divider/moments/closing），无 code 版式。
- 色块拼贴的骨架感转译为「几何静物台」：bh-circ / bh-tri / bh-rect（clip-path 三角）
  只在 cover/divider 页尾出现一组，尺寸由骨架内联给出；色块不进正文卡，卡保持
  藏青描边白卡（对应上游 rgba(0,0,0,.3) 描边）。
- 时间线圆点做成几何轮换（圆 / 方 / 菱 / 环），对应上游「形状是视觉主角」的母题。
- 包豪斯黄在上游藏在画布里，本模板提亮为 --gold #E8A400 用于第三编号块与菱形节点，
  在暖黄画布（letterbox 中段 #FBF5CE）上仍压得住。
- 字体栈：Inter / Noto Sans SC（900 黑体标题），不新增 webfont 文件。
