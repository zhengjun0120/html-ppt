# 包豪斯 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律粗壮几何黑体（h1/h2 已内建 900 与微宽字距），正文常规字重、层级分明；
  禁衬线、禁手写体、禁圆体。
- 语气是「宣言 + 课堂人话」：讲形状与颜色的脾气，用具体的物与动作（轮子、屋顶、砖墙），
  不写抽象大词；史实部分给年份与出处。
- 数字与年份直接用黑体呈现（bh-stat-v 已内建），不要给数字换字体。

## 结构纪律（几何是主角）

- 红黄蓝只用在几何与编号上：题签方块、编号色块、几何静物（bh-circ / bh-tri / bh-rect）、
  时间线圆点、巨号数字与行动钮。卡永远是藏青描边白卡，禁把卡底做成大色块。
- 几何静物（bh-stage）一页至多一组，放页尾留白处；尺寸由骨架内联 style 给出，别自创形状。
- 不对称制造张力，但每个元素都落在隐形网格上：内容块每页不超过两组 + 页脚。
- 色块上的字用奶油色（骨架已定），禁在原色上叠深灰小字。

## 禁令

- 禁柔和曲线与有机形状；一切几何只允许圆、三角、方与其旋转。
- 禁复杂渐变与照片级图像（画布渐变与角落静物已由模板衬底，正文不再画）。
- 禁超过三种以上的强调色：红、蓝、黄之外，只允许藏青与奶油承担结构。
- 禁 emoji、禁 AI 腔；禁编造精确数字——数据必须给口径与来源（bh-src 写在页尾）。
- 禁让装饰抢走几何构成的主角地位：正文密度保持低到中。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 呈现，数值 ≤6 字符；史实年份放时间线（moments）。

## 节奏

- 讲座顺序保持完整：cover → contents → metrics → divider → keynotes / split →
  moments → quote → closing（布置作业压轴）。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，是大师之言的压轴一笔。
- divider 在 8 页以上的 deck 至少出现 1 次；史实页与练习页穿插，不要连排。
