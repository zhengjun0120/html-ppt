# 学术论文 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 衬线主导：标题与正文都是 Georgia/宋体栈（h1/h2/.lede 已内建）；刊名、卷期、节号、时间点、
  图表注用等宽字体（ap-jmeta / ap-kicker / ap-no / ap-figcap 已内建）。不要混入黑体粗标题或圆体。
- 语言要「论文口吻」：每个论断带出处或口径（像"入围文献中 43% 报告了无回应处理"），
  不写营销形容词；术语可直接内嵌英文（coverage error、weighting）。
- 图表注一律以「注：」或「Fig. N」开头，斜体刊名只出现在期刊头。

## 结构纪律（蓝色必须可溯源）

- 学术蓝只允许出现在五处：节号与编号（ap-kicker / ap-no / ap-tl-dot / ap-tl-t）、关键数字
  （ap-stat-v）、摘要标签（ap-abs-label）、强调药丸（ap-pill-accent）、收尾按钮（ap-btn）。
  禁把蓝色用于大标题或大面积色块。
- 卡只有一种：白纸面 + 极淡描边 + 方角（ap-card）。禁阴影、禁圆角大卡、禁彩色卡底。
- 章节编号连续真实（1. / 2.1 / 01），页面顺序与编号一致，禁跳号。
- 页顶蓝条与纸面渐变由模板自动衬底，正文不要手绘装饰线。

## 禁令

- 禁 emoji；禁彩色背景、装饰性字体、花哨排版。
- 禁 AI 腔（「颠覆性」「革命性」一律换成可检验的陈述）。
- 禁编造精确数字：数据必须给口径与来源（metrics 用 ap-figcap 写「注：来源——」）；
  引文出处必须真实，禁给名言安错作者。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 论文顺序保持完整：cover → contents → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是论文的「题记」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
