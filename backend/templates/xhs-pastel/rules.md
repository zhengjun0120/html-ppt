# xhs-pastel · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 语气与语言

- 小红书体：标题像跟朋友说话（"放慢一点""先问自己"），不写书面腔（"综上所述""首先其次""值得一提的是"）。
- 正文禁 AI 腔：禁"在当今快节奏的时代""赋能""抓手""不仅…更是…"；一句一个画面，句号结尾的完整句。
- xp-chip / xp-kicker 惯用小写英文短语（如 `a soft manifesto`、`chapter one`），是杂志感的一部分；
  中文正文里不要夹无意义的英文，代码与单位除外。
- 强调色词（`<em>` / `.rose` / `.mint`）是标题里的点缀：每次 ≤4 字、每页最多 2 处，不准整句上色。

## emoji 政策（本模板与 tech-sharing 相反，源自 emoji 装饰风）

- emoji 只准出现在 steps-3 的 `xp-num` 装饰位（每卡一个、每页最多 3 个）。
- 正文句子、卡片说明、金句里一律不放 emoji；thanks 页可在文末放一个 ♡，此外不加。

## 禁令

- 禁半截句：卡内说明 22-45 字，一句论断 + 一句展开，句号结尾。
- 禁编造精确数字：donut-stat 的数字要有出处，没有就用量级或约数（"约 4 小时"）。
- 禁连续 3 页同版式：grid-2x2 是主力不是万能，中间用 checklist / quote-card 换气。
- 禁在骨架外发明新类名；颜色只走 token（`--xp-*`），唯一例外是 layouts.md 骨架里
  已写明的 style 与 donut SVG 的分段色值。

## 密度

- 每页可见文字 80-200 字（prompt 页代码另计，8-16 行）；低于下限会被写入门禁直接拒收。
- 卡片说明 22-45 字：一句论断 + 一句展开，句号结尾的完整句，不写半截句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回。
- **数字纪律**：关键数字/对比一律 donut-stat 呈现（段长 = 占比% × 6.28），不准埋进句子里。

## 节奏

- chapter（提问式章节页）在 8 页以上的 deck 至少出现 1 次；
- 数据页（donut-stat）与代码页（prompt）穿插在内容页之间，不要连排；
- cover → …内容… → steps-3 → thanks 的骨架顺序保持完整。
