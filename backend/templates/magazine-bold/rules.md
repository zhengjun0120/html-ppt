# 杂志大字 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律超大衬线（h1/h2 已内建 Georgia/宋体栈与 900 字重），正文用轻无衬线宽行距（lede 已内建 Inter 300），粗细对话是这套排版的呼吸。不要用无衬线做标题、不要加粗正文。
- 语气要「杂志主笔」：写现场、人物与一笔账（像"摊位费一晚六十元"），不写通稿腔。
- 数字用衬线大字呈现（mb-stat-v 已内建），来源与口径用轻无衬线小字。

## 结构纪律（大字是身份）

- h1/h2 每页最多一组，让字号本身成为画面；不要为了塞内容缩小标题——宁可删内容。
- 琥珀橙只允许出现在四处：荧光笔短杠（mb-bar / mb-kicker 自带）、关键数据（mb-stat-v / mb-n / mb-tl-dot）、题签（mb-pill-accent）、按钮（mb-btn）。禁橙色正文、禁大面积橙色色块。
- 卡只有一种：奶油白 rgba(255,255,255,.92) + 极淡金描边（mb-card）。禁重阴影、禁暗色卡、禁冷色调。
- 巨型水印字 mb-mark 一页至多一个，1-2 字，只放留白处（右下），禁放正文数据页。

## 禁令

- 禁 emoji；禁暗色背景、禁冷色调、禁密集小字号排版。
- 禁 AI 腔（营销形容词串）；杂志的腔调来自具体的事实与一笔账。
- 禁编造精确数字：报道数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；多论点用 keynotes 三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：报道数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 翻页顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是封面的「压轴金句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
