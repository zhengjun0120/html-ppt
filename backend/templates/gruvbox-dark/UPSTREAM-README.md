# gruvbox-dark（Gruvbox 暗）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/gruvbox-dark`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：标题 #ebdbb2 暖白、正文 #d5c4a1 暖灰，强调 #fe8019 琥珀橙与 #b8bb26 苔绿；
  背景 radial-gradient（#282828 → #1d2021 → #16191a）如炭火；卡片 rgba(40,40,40,.8)，
  边框 rgba(168,153,132,.25) 温暖棕灰描边。
- 排版：等宽字体，终端感是核心美学；vim 语法高亮配色可自然融入。
- 布局：暗色卡片浮在更暗的背景上，可借终端窗口感；代码/终端只在内容需要时当主角。
- 禁忌：现代科技感、冷色调、高饱和蓝紫、现代 IDE 质感——保持终端的质朴与暖色核心。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 10 版式骨架（9 基础 + code 代码示例），属深色科技/终端类模板的附加版式。
- 强调色在琥珀橙 #fe8019 与苔绿 #b8bb26 之外，补入 gruvbox 官方色板的沙黄 #d79921
  作二级强调（编号、时间点），三色分工写进 rules.md 的身份纪律。
- 上游预览的琥珀/苔绿角部辉光与 vim 状态栏母题，转写为 .slide::before/::after 的
  环境辉光 + 顶部橙绿细条 + 极淡扫描线（z-index:-1，每页自动衬底，不进骨架）。
- letterbox 底色 --bg 取径向渐变中段 #1d2021，翻页与深浅过渡不跳色。
- 字体栈：全局 JetBrains Mono（拉丁）+ Maple Mono（中日韩）+ Noto Sans SC 兜底，
  均为仓库自托管字体，未新增 webfont 文件。
