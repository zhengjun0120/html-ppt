vimrc 减脂三步

247 行，怎么瘦到 86 行

不许一次删光。先全量注释，回到可跑的最小集过一周；没被想念的行，下一周才准真删。判断只有一条：这行配置，最近三十天真的用到过吗。

每轮删除都打一个 git 标签，随时能整批回滚。

一周观察期 删前先打 tag
[01]

全量注释旧配置，原样跑满一周

[02]

只留三十天内翻过牌的行

[03]

定稿 86 行，打 tag 长期归档

现场演示 · 配置即文档

一份能背下来的 vimrc

~/.vimrcvimrc
" 86 行定稿节选 —— 每行都背得出理由
filetype plugin indent on
set number relativenumber
set ignorecase smartcase
set updatetime=300
nnoremap <leader>w :write<CR>
nnoremap <leader>h :nohlsearch<CR>
nnoremap <leader>e :edit ~/notes.md
colorscheme gruvbox
NORMAL · 86 行节选 9 行utf-8 · :wq 保存

这九行覆盖九成日常操作；留下的行，每月翻牌率都超过一次。
