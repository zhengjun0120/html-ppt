# catppuccin-latte（Catppuccin 拿铁）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/catppuccin-latte`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。
配色体系另致敬上游所指的 Catppuccin 主题家族（MIT）。

## 上游风格要点摘录（原 SKILL.md 大意）

- 气质：「开发者午后的温柔版本」——浅灰底如拿铁的奶泡，柔和蓝青粉彩轻轻浮现；
  证明浅色也可以很开发者，不需要暗色主题也能写出优雅的代码。
- 配色：深灰标题、中灰正文，蓝与青是浅底上的两颗糖果；背景浅灰蓝渐变如拿铁的层次，
  白底半透明卡片配柔和灰蓝描边。
- 排版：等宽或开发者友好字体，字重偏轻到中等；整体像一份精心排版的 README。
- 布局：浅色卡片在浅灰底上，层级靠微妙色彩和边框区分；宽松舒适，代码块与文字交替。
- 适合：开发者友好的技术分享、开源项目介绍、团队内部代码 Review。
- 禁忌：过于正式或企业化的排版、过于花哨或高饱和的颜色、丢掉开发者友好的核心气质、
  让浅色变成「无聊」。

## 转换说明

- 上游只有一个 1600×900 单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 10 版式骨架（基础 9 版式 + code 代码版式，编辑器类模板按规范附加 code）。
- 底色取 Catppuccin Latte 官方 base #EFF1F5；糖果三色取同族薰衣草 #7287FD /
  青 #179299 / 粉 #EA76CB，按「结构 / 内容 / 提醒」划车道；文字用 text #4C4F69 与
  subtext1 #5C5F77（对底实算约 7.1:1 / 6.4:1），不吃掉浅色的可读性。
- 上游预览的「奶泡光斑」母题做成 .slide::before/::after 的 radial-gradient 柔光斑
  （z-index:-1，画在内容之下），每页自动衬底、不进骨架，生成侧零成本。
- 代码版式做成浅色编辑器窗口母题（标题栏三圆点 + 文件名 + 语言标签 + 等宽代码块），
  语法色按三颗糖的车道分配，demo 页放主题色定义 JSONC 真实片段。
- 字体栈：Inter + Noto Sans SC（正文）与 JetBrains Mono（编号/数据/代码），均为仓库
  自托管字体，不新增 webfont 文件。
