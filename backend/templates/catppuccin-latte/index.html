第三段 · 色板设计

三颗糖果，
各管一摊。

浅色主题最怕颜色打架：我们把强调色砍到三颗，再给每颗划好车道，谁也不越线。

结构用薰衣草 内容用青
拿铁主题组 · 2025
内测版有五个强调色，用户反馈「不知道看哪」。砍到三颗、划车道，是这版最大的设计决定。

三颗糖的车道

#7287FD

薰衣草管结构

关键词、缩进参考线、当前行：结构元素统一走薰衣草，扫读时眼睛不会迷路。

#179299

青管内容

字符串、函数名、成功状态：内容层交给青色，和结构层永远不打架。

#EA76CB

粉管提醒

粉只出现在需要回头的地方：未保存标记、断点、报错。一屏至多一处。

拿铁主题组 · 2025
车道划分的检验法在下一页：转成灰度看层级。颜色可以调，车道不能换。

设计方法

对比度是设计出来的

浅底上的深字不是随手挑的。正文拿铁灰 #4C4F69 对底实算 7.1:1；注释灰退到 4.4:1——注释就该退后，但退得不看不见。

我们的检验法：把设计稿转灰度，结构层仍要比内容层深一档，才算合格。

灰度检验 退后不消失
1

定底色：奶白 #EFF1F5，白纸感但不上炫

2

定正文：#4C4F69，对比度过 AA 线再留余量

3

定点缀：三颗糖按「结构/内容/提醒」分工

拿铁主题组 · 2025
三步的顺序不能换：先底、再正文、最后点缀。从点缀开始调的主题，最后都会变花。

色板速览 · 照抄即可

把色板写进主题

latte-colors.jsoncJSONC
{
  "editor.background": "#eff1f5",
  "editor.foreground": "#4c4f69",
  "keyword":  "#7287fd",   // 薰衣草：结构
  "string":   "#179299",   // 青：内容
  "comment":  "#9ca0b0",   // 灰：退后一档
  "editorError.foreground": "#ea76cb"  // 粉：提醒
}

八行就是整份色板的分工表：结构、内容、提醒各就各位，注释退后一档。
