# catppuccin-mocha（Catppuccin 摩卡）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/catppuccin-mocha`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。
配色体系另致敬上游所指的 Catppuccin 主题家族（MIT）。

## 上游风格要点摘录（原 SKILL.md 大意）

- 气质：深灰底色如摩卡咖啡的表面，柔和的蓝与青在其中轻轻浮动；「长时间凝视也不会疲倦」，
  每一帧都像透过磨砂玻璃看到的温柔世界。
- 配色：柔蓝白标题、灰蓝正文，柔蓝与浅青是「摩卡中的两颗糖果」；暗色卡片在更暗的背景上，
  边框是极淡的灰蓝描边，层级靠柔和色彩区分而非硬边框。
- 排版：等宽或开发者友好字体，字重偏轻到中等；代码展示是这个风格的自然场景。
- 适合：开发者内部分享、长时间技术培训、代码 Review、开源项目介绍。
- 禁忌：过亮或过饱和的颜色、硬边框高对比元素、「酷炫」效果、用纯黑替代深灰破坏层次。

## 转换说明

- 上游只有一个 1600×900 单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 10 版式骨架（基础 9 版式 + code 代码版式，深色开发者模板按规范附加 code）。
- 底色取 Catppuccin Mocha 官方 base #1E1E2E（用户指定口径），糖果三色取同族
  薰衣草 #B4BEFE / 粉 #F5C2E7 / 青 #94E2D5 作语法与点缀分层；正文用 text #CDD6F4 /
  subtext0 #A6ADC8 保对比度，不落入上游警告的「纯黑替代深灰」。
- 上游预览的「柔光圆点」母题做成 .slide::before/::after 的 CSS radial-gradient ambient 层
  （z-index:-1，画在内容之下），每页自动衬底、不进骨架，生成侧零成本。
- 代码版式做成终端窗口母题（标题栏三圆点 + 文件名 + 语言标签 + 等宽代码块），
  语法色用薰衣草/粉/青/注释灰四档，demo 页放 starship.toml 真实片段。
- 字体栈：Inter + Noto Sans SC（正文）与 JetBrains Mono（编号/数据/代码），均为仓库
  自托管字体，不新增 webfont 文件。
