摩卡的三原则

三颗糖果，各管一摊

#B4BEFE

薰衣草管结构

关键词、目录编号、按钮底：凡是「骨架」的位置都用它，眼睛扫过去能原路找回来。

#94E2D5

青管路径成功

路径、对钩、构建通过：给「找得到」和「没问题」一个专属颜色，状态一眼可辨。

#F5C2E7

粉只给字符串

粉是全桌最甜的糖，只留给字符串与高亮提醒，一屏别超过两处，多了会腻。

动手环节

打开配置，只改三处

打开 starship.toml，你会想改一百个字段。今晚请只改三处：提示符符号、目录颜色、耗时提醒——其余保持上游默认，将来升级才不会痛。

验收标准：改完重启终端，要能一眼说出哪个颜色管什么；说不出来就是改多了。

40ms 预算 三处封顶
1

备份：复制一份原配置，文件名带上当天日期

2

改色：只动 character 与 directory 两个小节

3

回测：跑一次构建，看青色对钩还在不在

终端自习室 · 2025
这三步今晚每个人都跟一遍。卡在第二步入场的，助教在连麦区逐个看配置。

实操演示 · 照抄即可

把原则写进配置

starship.tomlTOML
# starship.toml —— 摩卡配色，只动三处
[character]
success_symbol = "[❯](bold #b4befe)"  # 薰衣草：安静的成功色
error_symbol = "[❯](bold #f38ba8)"   # 红只留给出错
[directory]
style = "bold #94e2d5"              # 青：路径一眼定位
[cmd_duration]
min_time = 40                       # 超过预算才显示
style = "bold #f9e2af"

符号与三处颜色，四十毫秒预算写进 min_time，其余字段原封不动。
