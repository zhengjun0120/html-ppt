# Catppuccin 摩卡 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线 + 等宽双声部：标题正文用 Inter/Noto Sans SC（h1/h2 已内建），编号、数据、
  题签、页脚一律等宽（mh-kicker / mh-n / mh-stat-v / mh-tl-t / deck-footer 已内建 JetBrains Mono）。
  不要引入衬线大标题或手写体。
- 语气要「工程师说人话」：写命令、耗时、行数、踩过的坑，不写抽象大词与营销形容词。
- 数字一律等宽呈现（模板已内建），不要给数字换字体。

## 结构纪律（三颗糖果是身份）

- 薰衣草 #B4BEFE 只管结构：题签、编号、大数字、按钮底、关键字。禁用于整卡底色或大面积色块。
- 青 #94E2D5 只管路径与成功：时间线圆点、语言标签、成功状态。禁挪作标题颜色。
- 粉 #F5C2E7 只管字符串与提醒：语法色、个别药丸点睛，一屏至多两处。粉是甜点，不是主菜。
- 卡只有一种：半透明暗面（mh-card），顶部渐变条卡（mh-card-top）仅限三卡要点。
  终端窗口（mh-term）是 code 版式专属，其他版式不准搬。
- 发光（glow）只允许出现在题签圆点、大数字与时间线圆点三处，禁给文字加辉光。

## 禁令

- 禁 emoji；禁纯黑 #000 背景、禁高饱和荧光色、禁硬边框粗描边、禁玻璃拟态滥用。
- 禁 AI 腩（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。
- 禁把代码塞进普通段落：代码只准进 code 版式的终端窗口。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。
- 代码块 6-10 行、每行 ≤56 字符；超长的代码拆成两页或裁剪到核心三处。

## 节奏

- 全份顺序保持完整：cover → contents → divider → keynotes / split → code → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；code 全份 1-2 页，它是「眼见为实」的实证页，不拿来凑数。
- quote 全份 deck 出现 1 次；divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
