# palace-ink-red（故宫墨红）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/palace-ink-red`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：宫墙墨红 #8C3232（砖红与酒红的沉淀感）为主色，玄石灰 #363636 做深色辅助区，
  宣纸米灰 #CAD2C5 做背景，米白灰 #DAD8CC / 浅宣纸 #E6E1D3 做深底上的文字，浅底正文用深炭灰 #2F2F2F。
- 字体：厚重现代无衬线，标题粗、方、稳，字距略收，像碑刻匾额；禁圆润可爱字体。
- 布局：大面积色块分层为核心，横向卡片、上下分区、强对齐；2-3 个宽大圆角矩形堆叠如色卡展板。
- 组件：大圆角卡片（约 24-40px），阴影大而实如装裱框；标签用细描边胶囊（浅米灰 #CFC8BA）。
- 质感：平面色块，哑光可触摸；可有 3%-6% 纸张颗粒；禁高亮渐变、金属反光、强发光。
- 禁忌：高饱和亮红与荧光色、复杂渐变、玻璃拟态、装饰纹样堆叠、文字过小过密、可爱圆体。

## 转换说明

- 原上游只有一个 16:9 的单页预览（左侧 38% 墨红竖块 + 右侧米灰展板）；本模板按本仓库
  deck-v2 契约重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 大色块身份收进 ambient 层：正文页左侧 16px 墨红竖脊、hero 页（封面/章节/收尾）顶部 14px 宽条、
  右上角低透明度窗棂格（.slide::before/::after，z-index:-1），每页自动衬底、不进骨架；
  没有照搬预览里 38% 宽的整块色柱——它会把每页可用宽度压掉三分之一，不适合承载 9 种版式。
- 阴影按本仓库纪律收为低透明度软投影（展板落位的层次感），不做上游允许的"大而实"硬阴影；
  全模板无渐变，哑光到底。
- 字体栈：标题与正文 'Noto Sans SC'（自托管 400/500/700）。上游要求 Heavy/Black 字重，
  本仓库自托管字体只有 700 一档粗面，跨渲染器合成加粗不稳定，故以 700 + 大字号 + 大字距
  补偿碑刻匾额的厚度；fonts 列表只写实际栈：Noto Sans SC / Inter，不新增 webfont 文件。
- 墨红 #8C3232 原样保留（上游已是收暗过的沉红，投屏不刺眼）。
