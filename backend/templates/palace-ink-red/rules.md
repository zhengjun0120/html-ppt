# 故宫墨红 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律黑体大字（h1/h2 已内建 Noto Sans SC 700 + 大字距，像碑刻匾额），正文同族无衬线中等字重；小字标签用大字距细字（pi-kicker / pi-pill / deck-footer 已内建）。不要引入楷体、宋体或手写花体标题，禁可爱圆体。
- 语气要「展板说明词」：克制、具体、有分寸（像"层层髹漆，阴干一日"），不写感叹号与口号。
- 数字与英文同族无衬线呈现；大数字只出现在 pi-stat-v，不准在句子里堆数字。

## 结构纪律（墨红是身份）

- 墨红只允许出现在六处：自动衬底色条（正文页左脊 / hero 页顶条，模板自带）、短尺 pi-rule、方印 pi-seal、编号块 pi-num、关键数据与强调（pi-stat-v / pi-tl-t / pi-pill-red）、实底按钮 pi-btn。禁把墨红用于整页背景、正文长段落或并列小色块拼贴。
- 卡只有两种：浅宣卡 pi-card（米灰纸底 + 24-32px 大圆角）、玄石灰深卡 pi-card-dark（一页至多一块）。圆角厚重感是身份，禁改直角或细边小卡。
- 分区靠色块分层：一页最多两组内容块 + 页脚；信息多就砍，不做第四块。
- 描边胶囊 pi-pill 是浅米灰细描边；强调态 pi-pill-red 一页至多两枚。

## 禁令

- 禁 emoji；禁渐变、发光、玻璃拟态、金属反光；禁高饱和亮红（#F00 系）与荧光色。
- 禁 AI 腔（赋能、引领、极致一类口号词，换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 展板顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是题铭的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
