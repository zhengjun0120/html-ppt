# 彩虹渐变 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板友好无衬线（h1/h2 已内建），字重中等偏厚、标题温暖但不厚重；不出现衬线宋体或手写体。
- 语气是庆祝的口气：写具体的动作与场景（像"冲线那一下"），不写空泛的欢乐大词。
- 数字用无衬线呈现（模板已内建），大数字只用模板内建的玫红→紫渐变。

## 结构纪律（七彩是身份，白是底）

- 七彩只做条、环、点：彩虹条 rg-stripe、题签丝带（rg-kicker 自带）、彩虹环编号 rg-n 与
  时间线圆点 rg-tl-dot、彩点芯片 rg-chip、数据顶线（rg-stat 自带）。禁七彩大色块直衬正文。
- 对比度纪律：正文一律海军蓝/钢灰（模板已内建），长文字优先放进白色卡 rg-card /
  rg-band；直接落在 wash 上的只有标题、lede 与胶囊——它们对柔彩底都有 ≥4.5:1 对比。
- 玫红是唯一强调色：rg-pill-accent、rg-tl-t、rg-stat-v 渐变起点。禁玫红当长正文色。
- 留白即节奏：一页最多两组内容块 + 页脚；彩虹丝带与页底浪是自动衬底，正文不要再画彩虹。

## 禁令

- 禁 emoji；禁深色或严肃元素、暗背景；禁把彩虹做成大杂烩（一页七彩装饰 ≤3 处）。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 庆典顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是欢呼的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
