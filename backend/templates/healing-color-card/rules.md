# 情绪疗愈色卡 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与小标题用圆润无衬线（模板已内建圆体栈），正文细体宽行距；数字用无衬线中黑体呈现。不要引入硬朗几何黑体、书法体或手写花体。
- 语气要「接住情绪」：写身体感受、具体动作与场景（像"睡前十次慢呼吸"），不写口号式大词，不用反问施压。
- 引文可用楷体（模板已内建），带一点手写感；正文不要混用楷体。

## 结构纪律（三色是母题）

- 色卡渐变只有三张：薰衣草紫、暖桃米、薄荷绿（hc-card-lav / -peach / -mint），一页至多一组三卡；小圆色板 hc-chip 是贯穿全份的身份记号，封面与引文页成组出现。
- 藕荷紫是唯一强调色：只用于关键数据（hc-stat-v）、圆点编号（hc-n / hc-tl-dot）与强调签（hc-pill-accent）。禁大面积藕荷紫底、禁给标题上紫色。
- 卡一律大圆角（模板已内建 28px），禁直角卡、禁硬阴影；分隔用虚线（模板已内建），不用实线表格。

## 禁令

- 禁 emoji；禁荧光色、暗黑背景、高饱和撞色。
- 禁 AI 腔（"赋能""治愈你的精神内耗"这类口号，换成具体的动作与身体感受）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格与锋利几何图形；对比类内容用 keynotes 的三色卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 一堂课的顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是这门课的「睡前一盏灯」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
