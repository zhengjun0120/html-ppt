# summer-warm-color（夏日暖色）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/summer-warm-color`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色「夏日碎片」色卡：晴空蓝 #20A1EE 与层次蓝 #58C3F6 撑天空，草绿 #9DDF67、嫩绿
  #DAF5A7 做草地，明黄 #FFF061 是温度来源；暖橙 #FE7F08、淡粉 #FFADDD、浅蓝紫 #A6B0FF
  做小面积呼吸点。蓝是主调，黄是温度，绿是生机，三者缺一不可。
- 排版：中文标题偏粗的毛笔/软笔手写体（字重 600-700），英文小标斜体手写体；正文圆润
  无衬线字重 400，托住标题不抢戏。
- 意象：带放射光芒的卡通太阳、棉花糖云朵、渐变草地、纸飞机、仰躺看天的小孩、圆形
  色卡阵列（5 个一组）。
- 布局：上场景 / 中标题 / 下色卡的三段式，圆角 16-24px 模块化卡片，留白保持天空呼吸感。
- 禁忌：高饱和霓虹荧光、尖锐几何与直角、复杂渐变 mesh 与硬阴影、大面积冷蓝灰无暖色、
  密集排版、奔跑式剧烈动感。

## 转换说明

- 原上游只有一个 16:9 单页预览（夏日碎片色卡页，无多版式结构）；本模板按本仓库 deck-v2
  契约重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 「上场景 / 中标题 / 下色卡」三段式改写为整页 ambient 层：天空→草地渐变 + 云朵 + 纸飞机
  （.slide::after inset:0）+ 放射太阳（.slide::before），z-index:-1 每页自动衬底；封面的
  五圆色卡阵列保留为骨架元素（sw-swatches）。
- 渐变整体调浅一档（原 #20A1EE 天空顶收为 #A9DEF6 级别），保证深海蓝 #16608F 标题与
  蓝灰正文在整页 4.5:1 级对比度；letterbox 底色取渐变中段 #C8EBF4，翻页不跳。
- 手写体以系统楷体栈（'STKaiti'/'KaiTi'）代替，不新增 webfont；暖橙收暗为 #C65508
  用于时间点等小字，保持浅底对比。
- demo 叙事改为「夏日冰饮产品线企划」，覆盖上游 styleCase（亲子/科普/疗愈之外的
  夏日休闲企划场景）。
