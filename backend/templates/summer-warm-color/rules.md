# 夏日暖色 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律软笔手写气质（h1/h2 已内建楷体栈），正文圆润无衬线、行距放宽；小字标签用云朵白胶囊（sw-kicker / sw-pill / deck-footer 已内建）。不要引入黑体粗标题、印刷衬线或锋利几何感字体。
- 语气要「躺下来看天」的松弛具体：写冰块、果肉、蝉鸣、出杯动作与人话，不写冲刺口号。
- 数字与英文用无衬线呈现（模板已内建），不要给数字加楷体。

## 结构纪律（阳光是温度）

- 阳光黄只允许四处：小太阳印 sw-sun、编号圆 sw-n、题签（sw-kicker 的粉点 / sw-pill-accent 黄底）、数据上边线 sw-stat 顶线。暖橙只做时间点（sw-tl-t）。禁把黄色或橙色铺成整页色块。
- 卡只有一种：白色半透明大圆角 + 柔投影（sw-card）。禁硬阴影、禁直角卡、禁玻璃拟态反光。
- 留白是天空的空白地带：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。
- 会写字的云 sw-cloud 只在 quote 页留白处一朵，云上短语 ≤6 字，禁放数据或正文。

## 禁令

- 禁 emoji；禁霓虹荧光色、强渐变 mesh、玻璃拟态。
- 禁尖锐几何、直角矩形、锋利细线——这套风格是圆润柔和的。
- 禁大面积冷蓝灰无暖色——必须有阳光黄的温度打底。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的口味、场景与动作）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是浮在时间线之上的那朵云。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
