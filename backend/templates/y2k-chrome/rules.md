# Y2K 铬 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线（Inter + Noto Sans SC 已内建），数字与英文标签走等宽（yk-n / yk-kicker / yk-stat-v / yk-tl-t 已内建），不要引入衬线、手写体或圆体。
- 英文点缀一律全大写 + 宽字距（yk-kicker 已内建 text-transform），像 2000 年的界面标签。
- 语气轻快但具体：写产品、材质、货架与人的动作，不写「赋能」「颠覆」这类抽象大词。

## 结构纪律（银铬是身份）

- 铬面渐变、高光斜扫与气泡光斑住在背景层（模板自动衬底），正文不要手画光斑或渐变块。
- 彩虹只允许出现在三处：标题彩虹条 yk-rainbow、数字块上描边（yk-stat 自带）、题签短线（yk-kicker 自带）。禁把彩虹铺满背景、正文或整卡。
- 文本级紫色只进 yk-pill-accent 与 yk-tl-t；正文与标题保持墨黑/深灰，不写浅色字。
- 卡只有一种：半透明白底 + 高光描边 + 大圆角（yk-card）。禁直角、禁小圆角、禁深色卡。
- 徽标 yk-orb / 编号 yk-n 是气泡母题的落点，一页至多一组大徽标。

## 禁令

- 禁 emoji；禁深色底与暗黑模式（Y2K 是银色的）；禁衬线与手写体。
- 禁直角卡片、小圆角按钮——所有容器保持大圆角或正圆。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的货与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，等宽大数字是主视觉，不准埋进句子里。

## 节奏

- 页序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是高光的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
