# 日光浅 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板人文无衬线 + 等宽双声部：标题正文用 Inter/Noto Sans SC（h1/h2 已内建，字重偏轻），
  编号、数据、题签、页脚一律等宽（sl-kicker / sl-n / sl-stat-v / sl-tl-t / deck-footer
  已内建 JetBrains Mono）。不要引入衬线大标题或圆体手写体。
- 语气要「实验室讲人话」：写对比度、色温、人数、实测步骤，每个结论带口径；
  像一本排印精良的教科书，严谨但不枯燥。
- 数字与色值一律等宽呈现（模板已内建），不要给数字换字体。

## 结构纪律（蓝青是身份）

- 日光蓝 #268BD2 只管强调：题签、大数字、链接、按钮底。禁用于整卡底色或大面积色块。
- 青 #2AA198 只管代码与成功：时间线圆点、语言标签、字符串语法色。禁挪作标题颜色。
- 黄 #B58900 只管数字与常量点睛，一屏至多两处。
- 卡只有一种：纸黄半透明纸片（sl-card），顶部蓝青条卡（sl-card-top）仅限三卡要点。
  纸面编辑器窗口（sl-term）是 code 版式专属，其他版式不准搬。
- 浅色纪律：文字只用深青系（#073642 / #586E75 / #93A1A1），禁纯黑 #000、
  禁纯白大色块、禁在暖黄底上用冷灰文字——那正是上游警告的刺眼来源。

## 禁令

- 禁 emoji；禁高对比刺眼配色、禁纯黑/纯白极端对比、禁硬边框粗描边、禁「视觉冲击」式大字报。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与实测步骤）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。
- 禁把代码塞进普通段落：代码只准进 code 版式的编辑器窗口。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。
- 代码块 6-10 行、每行 ≤56 字符；代码页只放一段，不堆叠多段代码或密集说明。

## 节奏

- 全份顺序保持完整：cover → contents → divider → keynotes / split → code → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；code 全份 1-2 页，它是「高亮眼见为实」的实证页。
- quote 全份 deck 出现 1 次；divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
