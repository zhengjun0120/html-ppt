# solarized-light（日光浅）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/solarized-light`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。
配色体系另致敬 Ethan Schoonover 的 Solarized 色板（其仓库以 MIT 类许可自由分发）。

## 上游风格要点摘录（原 SKILL.md 大意）

- 气质：「科学调校的视觉舒适」——暖黄底如旧书纸张，低眩光让眼睛在八小时会议后依然从容；
  不是随意挑的「米色」，而是经过色彩科学计算的最优解。
- 配色：深青标题 #073642、石板青正文 #586E75，蓝 #268BD2 与青 #2AA198 是低对比中的清晰
  标记；背景从暖黄 #FDF6E3 到米灰的三段渐变模拟旧纸张，卡片与背景同色系、青灰柔和描边。
- 排版：等宽或人文无衬线字体，字重偏轻；行距宽松，让文字在暖黄底上自由呼吸。
- 布局：卡片与背景和谐一体，区块间用充足留白分隔，不依赖硬边框；像一本排印精良的
  教科书——严谨但不枯燥。
- 适合：长时间工作坊、教学培训、技术教学、学术讨论。
- 禁忌：高对比刺眼颜色、纯白/纯黑极端对比、暖黄底上用冷灰文字、追求「视觉冲击」。

## 转换说明

- 上游只有一个 1600×900 单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 10 版式骨架（基础 9 版式 + code 代码版式，浅色代码主题按规范附加 code）。
- 纸底三段渐变取上游口径（#FDF6E3 → #E9E1C9），letterbox 底色 #F3ECD6 取渐变中段，
  翻页不跳；正文 #586E75 对底实算约 5.0:1，口径写在 demo 数据页。
- 上游预览的「横格纸纹」母题做成 .slide::after 的 repeating-linear-gradient ambient 层，
  暖光做 ::before（z-index:-1，画在内容之下），每页自动衬底、不进骨架。
- 卡片与药丸采用方正小圆角（8-10px），与拿铁系的胶囊大圆角区分，呼应「教科书」气质。
- 代码版式做成纸面编辑器窗口母题（标题栏三圆点 + 文件名 + 语言标签 + 等宽代码块），
  语法色按 Solarized 语义：关键字蓝、字符串青、函数紫、常量黄、注释青灰。
- 字体栈：Inter + Noto Sans SC（正文）与 JetBrains Mono（编号/数据/代码），均为仓库
  自托管字体，不新增 webfont 文件。
