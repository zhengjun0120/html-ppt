# 北极冷 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线（Inter + Noto Sans SC 已内建），字重克制：标题 600-700，不追求超粗；
  数字、日期与英文标签一律等宽（ac-n / ac-kicker / ac-stat-v / ac-tl-t 已内建 JetBrains Mono 栈）。
- 语气是「公报体」：客观、可核验、给口径——写航程、样本、设备与动作，
  不写抒情形容词，不做口号式收尾。

## 结构纪律（冰川青是身份）

- 冰川青只允许出现在六处：题签细线（ac-kicker 自带）、关键词 ac-hl、编号与徽牌 ac-n、
  指标名 ac-stat-l、时间点 ac-tl-t、行动钮描边 ac-btn。其余文字一律冰白/雾蓝灰。
- 数字是主角：关键数据走 metrics 的等宽大数字，图表心智由时间线（ac-tl）与三卡承载；
  文字永远为数字让位。
- 卡只有一种：半透明冰面底 + 细描边 + 卡顶冰川青细线（ac-card）。禁纯白卡、禁厚阴影。
- 无发光、无玻璃拟态、无渐变大字——冷静不是冷漠，是装饰退到 ambient 层之后。

## 禁令

- 禁 emoji；禁暖色与活泼元素；禁手写体、装饰字体；禁发光与毛玻璃。
- 禁让装饰抢走数据的注意力：一页至多一个 ac-hl 关键词，至多一枚徽牌。
- 禁 AI 腔（口号式动词、营销形容词一律换成可核验的事实与动作）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），口径优先写「科考队公报」
  或船载记录；没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，等宽大数字是主视觉，不准埋进句子里。

## 节奏

- 页序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是公报的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
