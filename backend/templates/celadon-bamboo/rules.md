# 青瓷竹影 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律 Georgia/宋体衬线高对比气质（h1/h2 已内建衬线栈），竖排短句与小印可用楷体，小字标签用无衬线（qc-kicker / qc-pill / deck-footer 已内建）。不要引入黑体粗标题、圆体或卡通字体。
- 语气要「题跋式安静的具体」：写器物、釉色、窑火与观展动作（像"看它先看颈部一线釉"），一页只讲一个核心观点，不写抽象大词。
- 数字与英文用无衬线细体呈现（模板已内建），不要给数字加衬线粗体。

## 结构纪律（朱砂是印，青瓷是线）

- 朱砂只允许出现在两处：印章 qc-seal、强调点缀（qc-pill-accent / qc-verse-accent）。关键数据用深青（qc-stat-v / qc-tl-t），禁用朱砂做数字。
- 青瓷绿三阶只出现在细线（qc-line）、圈码（qc-n / qc-tl-dot）与竹影 ambient 里，禁大面积色块、禁渐变色底。
- 卡只有一种：半透明纸面底 + 低对比描边（qc-card）。禁硬阴影、禁强投影、禁纯白死底、禁圆角大卡。
- 留白承托文字：一页最多两组内容块 + 页脚；右侧竹简竖条是衬底，内容与药丸别贴着它排。
- 竖排 qc-verse 只放留白处，一页至多一条，内容是诗句或四字短语，禁放正文数据。

## 禁令

- 禁 emoji；禁荧光色、强投影、厚重 3D、金属质感、强对比商业按钮。
- 禁把版面塞满数据表格；禁粗黑边框；对比类内容用 split 或 keynotes 的三卡承载。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 观展顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是展览的「压轴题跋」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
