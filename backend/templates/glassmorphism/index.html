玻璃三要素

玻璃的三个脾气

层次 · 深度

前后景分离

背景光斑与卡片之间隔了一层 18px 磨砂，越近越清晰，越远越朦胧。

光影 · 边界

高光描边

1px 半透明白描边勾出轮廓，亮部在上、暗部在下，玻璃就有了厚度。

呼吸 · 留白

卡片不塞满

每张玻璃卡只讲一件事，留出雾面呼吸空间，密度高了通透感就没了。

云雾 UI · v2.0 发布 · 2026
三要素按"深度—厚度—呼吸"的顺序讲，正好对应玻璃参数表的三个变量组。

接入三步

把云雾装进工程

云雾按需打包，样式与行为分离。引一次样式表，再注册用到的组件，未使用的部分不会进入产物，首屏体积保持轻盈。

判断是否适合玻璃：背景必须有色彩或光影，纯白页面上玻璃会失去意义。

按需引入 MIT 协议
01

安装：npm install yunwu-ui 拉取 2.0 组件包

02

引入：全局样式一次引入，含玻璃参数变量

03

使用：按页面注册组件，树摇自动裁剪体积
