# 磨砂玻璃 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线：标题 800 字重紧字距（h1/h2 已内建），正文常规字重宽行距；小字标签用 600 字重宽字距（gl-kicker / gl-chip / deck-footer 已内建）。不要引入衬线标题、手写体或圆体。
- 语气要「发布会讲稿」：写组件、参数、场景与人话（像"光斑在后退，玻璃在呼吸"），不写抽象大词。
- 数字与英文用无衬线呈现（模板已内建），关键数字交给 metrics，不要埋进句子里。

## 结构纪律（玻璃是身份）

- 玻璃卡只有一种：rgba 白底 + backdrop-blur + 细白描边 + 顶部高光（gl-glass），长文本用加实档（gl-glass-deep）。禁实色卡、禁硬边框、禁把卡片做成不透明——玻璃不透光就不成立。
- 柔紫与青蓝只允许出现在五处：题签短线（gl-kicker 自带）、大数字（gl-stat-v）、时间点（gl-tl-t）、强调药丸（gl-chip-accent）、行动钮（gl-btn）。禁把紫蓝用于正文、大面积色块或整卡底色。
- 文字对比纪律：玻璃卡内一律深墨（#0F172A / #334155 / #475569）；渐变文字（gl-quote / gl-stat-v）两端色已按深色配好，禁再自行改浅。
- 光斑住在 ambient 层，由模板自动衬底；不要在骨架里手画光斑、渐变圆或模糊块。

## 禁令

- 禁 emoji；禁荧光色、金属质感、深色底——这个风格是「浅雾面上浮白玻璃」。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的组件名与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，口径写进卡内或页尾。

## 节奏

- 发布会顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是光斑最亮的一帧。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
