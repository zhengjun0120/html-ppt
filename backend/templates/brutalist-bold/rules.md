# brutalist-bold · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 单强调色纪律

- 全模板只有三种东西：纸底 #F4F4F0、碳黑 #111、一个强调色（默认警戒红 #E61919；变体整体替换为工程蓝/安全绿，一页仍然只有一个强调色）。
- 强调色只准出现在登记过的位置：b-rule 通栏粗线、b-mark 红块、b-strike 删除线、b-val-red 数据高亮、b-hot 热板顶边、b-blade-red 红色编号、b-term 左侧红竖线。别处不准上色。
- 禁止第二强调色、禁止渐变、禁止投影、禁止半透明（所有线和底都是实色）、禁止 border-radius——全部直角 90°。

## 字体纪律

- 宏字体：Inter 900 全大写，letter-spacing -0.03 ~ -0.06em，line-height 0.9-0.95。封面/章节幕/收尾主标 120-160px 级，内容页 h2 约 64px。
- 微字体：所有元数据/编号/标签/落款一律 JetBrains Mono 全大写、字距 0.05-0.1em、≥15px；中文数字混排时数字部分自然走 mono。
- 正文与说明 ≥18px，代码 18px；除装饰巨字（b-num 等）外无 <14px 的字。

## 结构纪律

- 分隔全靠实线：顶栏/页脚 2px 墨线、清单行间 1px 墨线、卡片用 `display:grid`+缝隙 2px 的刀锋细线（b-blade），节与节之间用 b-rule 红色通栏粗线。
- 巨号描边数字（b-num）一页最多一个，只做背景锚点，不准压住正文可读性。
- 顶栏 b-top（编号 + 条码）与页脚 deck-footer 是每页的机械外框，照骨架保留；不要发明新的页面骨架。

## 符号与文案

- 装饰符号只用这些：`[ SECTION ]`、`>>>`、`///`、`+`（网格交点）、`|` 条码竖线、机械编号（REV 2.6 / UNIT D-01 式）。
- 禁 emoji；禁「赋能 / 提升体验 / 卓越 / 引领 / seamless / elevate」这类空话——写真实的编号、时间、人名、数量、判罚口径。通报类内容要像车间里贴出来的文件，不像发布会通稿。
- 禁编造精确数字：没有台账来源就用量级或区间，来源行不可省略。

## 密度

- 每页可见文字 100-220 字（代码页另计，代码 8-14 行）；低于下限会被写入门禁直接拒收。
- 卡片/表格说明 14-45 字（各版式有区间）：写口径、写时限、写判罚，句号结尾的完整句，不写半截句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回。
- **数字纪律**：关键数字/时限/底数一律 stat-plate、split-spec 呈现，不准把数字埋进句子里。

## 节奏

- section（章节幕）在 8 页以上的 deck 至少出现 1 次；
- 数据页（stat-plate）与代码页（code-run）穿插在内容页之间，不要连排；
- cover → manifest → …内容… → closing 的骨架顺序保持完整；
- 同一版式最多连用 2 页；一页只有一个视觉重心（巨字或巨号，不要两个都抢）。
