# 玫瑰松 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文用人文无衬线（Inter + Noto Sans SC，已内建），字号优雅但不夸张，行距是暗色的呼吸；小字标签与数字用等宽点缀。
- 引文页是全模板唯一的衬线时刻（rp-quote / rp-t / rp-stat-v 已内建 Georgia/宋体栈），不要在别处再引入衬线大字。
- 语气要「设计与工程互相尊重」：写槽位、职责、对比度与人话（像"改名字要过 RFC，改色值不用"），不写抽象大词。

## 结构纪律（玫瑰是心跳）

- 玫瑰粉是唯一的心跳色：题签细线、关键数字 rp-stat-v、时间点 rp-tl-t、强调药丸 rp-pill-accent、按钮 rp-btn、芯片圆点。禁把玫瑰用于大标题、整卡底色或大面积色块。
- 金色只管编号（rp-n / rp-tl-dot），松青只管语言标签 rp-lang 与松枝衬底；三色分工不互换。
- 卡只有一种：暮色半透明 + 紫灰轻描边 + 大圆角（rp-card，22px）。禁 90 度直角卡、禁纯白死底、禁硬阴影。
- 柔和终端 rp-term 只在 code 版式出现，一份 deck 至多 1-2 页；代码 6-10 行、行长 ≤56 字符。

## 禁令

- 禁 emoji；禁霓虹色、金属渐变、重玻璃拟态、锐利几何。
- 禁把暗色压成纯黑：底色保持紫调（模板已内建暮色渐变），层级靠亮度差不靠描边加重。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的槽位、流程与人话）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 建议顺序：cover → contents → divider → keynotes / split → code → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是暗色里的「一次深呼吸」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排；code 版式全份 1-2 页。
