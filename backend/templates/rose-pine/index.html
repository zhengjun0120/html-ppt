三条设计约定

暗色里的温柔纪律

语义

名字先于色值

每个槽位先写用途再写色值；改名字要过社区 RFC，改色值不用。

及格线

正文对比 4.5:1

正文对底色一律过 AA；玫瑰粉只给标题与图标，不排小正文。

呼吸感

层级靠亮度差

底、面、浮三层只用亮度分家，边框轻到几乎看不见为止。

暮松色板 · 2026
三条约定是 v2.0 的 RFC 摘要，完整文档在仓库 wiki。

  "base": { "bg": "#191724", "surface": "#1f1d2e" },
  "text": { "hi": "#e0def4", "lo": "#908caa" },
  "rose": { "accent": "#eb6f92" },
  "gold": { "reward": "#f6c177" },
  "foam": { "calm": "#9ccfd8" },
  "meta": { "slots": 12, "contrast": "AA" }
}
