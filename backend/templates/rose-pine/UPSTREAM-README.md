# rose-pine（玫瑰松）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/rose-pine`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：标题 #e0def4 薰衣草白、正文 #908caa 柔灰紫，强调 #eb6f92 玫瑰粉与 #31748f 松青；
  背景 radial-gradient（#191724 → #1f1d2e → #26233a）如暮色；卡片 rgba(25,23,36,.75)，
  边框 rgba(129,123,144,.2) 柔和紫灰描边。
- 排版：人文无衬线或衬线字体，带一点手写的温度；标题优雅不夸张，正文行距宽松。
- 布局：柔和的暗色布局，卡片边缘不锐利，留白是暗色的呼吸；玫瑰粉只出现在最需要的地方。
- 禁忌：硬边框、霓虹色、过于锐利的几何、纯黑（保持紫调）、压抑沉重的暗色。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 10 版式骨架（9 基础 + code 代码示例），属深色科技类模板的附加版式。
- 强调色在玫瑰粉之外，改用 rose-pine 主题的全家桶：金 #f6c177 管编号、泡沫松青
  #9ccfd8 管语言标签（比上游 SKILL 的深松青 #31748f 在暗底上更亮、更贴「温柔」），
  三色分工写进 rules.md 的身份纪律。
- 上游预览的玫瑰/松青角部辉光与有机形色块，转写为 .slide::before 的环境辉光 +
  ::after 的右下松枝线描 data-URI SVG（z-index:-1，每页自动衬底，不进骨架）；
  卡统一 22px 大圆角轻描边，呼应「卡片边缘不锐利」。
- letterbox 底色 --bg 取径向渐变中段 #1f1d2e，翻页与深浅过渡不跳色。
- 字体栈：正文与标题 Inter + Noto Sans SC；引文/篇名/大数字走 Georgia + 宋体系统衬线
  （全模板唯一的衬线时刻），数字与代码用 JetBrains Mono；均为既有字体，未新增 webfont。
