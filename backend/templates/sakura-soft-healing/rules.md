# 樱花治愈 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板圆润黑体（圆体栈已内建）：标题 700 字重但字距放宽、行高近两倍，像轻声说话。不要引入衬线大标题、楷体宋体、书法体或锋利几何黑体。
- 语气要「慢生活的具体」：写触感、气味、时刻与人话（像"上脸十分钟，不刺痒就是对的"），不写抽象大词，不用感叹号轰炸。
- 数字用圆润无衬线呈现（模板已内建），不要给数字换字体。

## 结构纪律（玫粉是唯一强调）

- 玫粉只允许出现在四处：强调药丸（ss-pill-rose）、关键数据（ss-stat-v）、时间点（ss-tl-t）、行动钮（ss-btn）。禁把玫粉用于大标题、大面积色块或整卡底色。
- 淡樱只做圆号（ss-n）、时间线圆点与数据顶线；湖水蓝与草绿只活在背景 ambient 里，禁进正文、卡片或药丸——它们是风景，不是信息色。
- 卡只有一种：半透柔白 + 暖棕细描边 + 玫粉柔光投影（ss-card）。禁深色卡、禁纯白死底、禁直角。
- 现代柔和日系，不是国风：禁印章、禁竖排文字、禁楷体宋体大标题、禁描红福字类装饰；少女粉也禁——这里的粉带灰度，是莫兰迪粉。
- 一页最多两组内容块 + 页脚；留白是治愈感的一部分，不要填满。

## 禁令

- 禁高饱和明亮色、纯黑大块、强烈明暗对比；所有颜色像蒙了一层薄雾。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是研发手记的「压轴一页」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
