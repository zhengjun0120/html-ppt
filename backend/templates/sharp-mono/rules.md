# 锐利黑白 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律最重的黑体气质（h1/h2 已内建 Archivo Black/Arial Black 栈、字重 900），正文无衬线常规字重；小字标签与数字用等宽（sm-kicker / sm-tag / deck-footer 已内建）。不要引入衬线、手写体或圆体。
- 语气要「宣言」：短句、肯定句、判断先行（像"空，不是没有"），不写解释性长句和客套话。
- 数字与英文一律等宽呈现（模板已内建），不要给数字换字体。

## 结构纪律（黑白就是身份）

- 全页只准无彩色：#000000 / #333333 / #666666 / #FFFFFF 与浅灰。出现任何一个彩色值都算事故。
- 黑色大块只允许出现在四处：反白元素（sm-tag-invert / sm-btn）、硬卡边框与硬阴影（sm-card 自带）、加粗大标题（h1/h2）、方块编号（sm-n / sm-tl-dot）。正文段落永远 #333333，不要纯黑。
- 卡只有一种：白底 3px 黑框 + 10px 硬阴影（sm-card）。禁圆角、禁模糊阴影、禁细于 2px 的边框。
- 反白块一页至多两处；黑白对比已经很强，信息模块保持少量且克制。
- code 版式的代码必须真实可读、能跑能讲，禁用 Lorem ipsum 或「……」省略。

## 禁令

- 禁任何彩色（连一点点缀都不行）；禁 emoji。
- 禁柔和：禁圆角、禁模糊 box-shadow、禁渐变彩色、禁玻璃拟态。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的判断与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → code / metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是宣言的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；code 版式只在有真实代码、配置或参数可展示时使用，数据页与内容页穿插，不要连排。
