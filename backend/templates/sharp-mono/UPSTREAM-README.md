# sharp-mono（锐利黑白）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/sharp-mono`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：无彩色系——标题 #000000 纯黑、正文 #333333，强调 #000000 与 #666666；
  背景 linear-gradient(160deg, #ffffff, #f5f5f5 55%, #e5e5e5) 白到浅灰过渡；
  卡片 rgba(255,255,255,0.96)、边框 #000000，阴影是硬阴影（偏移 4-6px、无模糊）。
- 排版：Archivo Black 或粗黑体，字重拉到最重，标题可以大到填满半个屏幕。
- 布局：大胆的对角线切割、大面积黑白色块极端对比；不对称但严格对齐网格；模块少而克制。
- 禁忌：任何彩色（连点缀都不要）、圆角、模糊阴影、细线边框、温馨柔和感。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 10 版式骨架（9 基础版式 + code 代码示例版式，终端窗口母题：三圆点 + 文件名 +
  等宽代码块）。
- 硬阴影统一取 10-12px 偏移、零模糊、零圆角（比上游 4-6px 更放得开，1920 画布下比例相当）。
- 对角线切割母题收敛为右上斜切色带（.slide::before，rotate 22deg + 硬阴影三连条），
  四角裁切线（.slide::after，8 个 background 层）呼应印刷母题；两层都是 z-index:-1 的
  ambient，每页自动衬底、不进骨架。
- 字体栈：标题 'Archivo Black'/'Arial Black'（系统回退），正文 Inter/Noto Sans SC，
  数字与小字 JetBrains Mono；不新增 webfont 文件。

## demo 叙事口径

demo 为「黑白版式的力量」设计讲座（虚构品牌「锐·字社」）：九级字阶、55% 留白占比、
27 件获奖作品均标注了内部统计口径与来源行，属演示用虚构数据。
