# 蒸汽波 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律衬线宽字距（h1/h2 已内建 Georgia/宋体栈 + .08em 字距），像大理石碑文；正文无衬线轻字重；小字标签、年份与数字用等宽（vw-kicker / vw-pill / deck-footer 已内建）。不要引入黑体超粗标题或手写花体。
- 语气要「美不需要理由」：感受先于论证，允许一句无厘头；但数据仍然要有口径与来源，怀旧不等于瞎编。
- 希腊字母与日文假名可做点缀，一页至多一处；竖排 vw-vert 同理只放留白处。

## 结构纪律（渐变是身份，不是正文）

- 粉 #FF71CE 与青 #01CDFE 只出现在三处：ambient（日轮/网格/柱影，模板自动衬底）、数据与时间线（vw-stat-v / vw-tl-t / vw-tl-dot / vw-n）、行动钮（vw-btn）。禁给正文文字上渐变色或荧光色。
- 正文永远灰白 #E2E8F0 或冷白 #F8FAFC，落在深紫底上；淡紫 #A99BC8 只准用于页脚、来源行与单位。禁把正文放到渐变亮区。
- 卡只有一种：半透明暗紫 + 粉描边 + 大圆角（vw-card）。禁硬黑框、禁锐利直角——锐利是隔壁 sharp-mono 的事。
- 竖排 vw-vert 只放留白处，一页至多一条，内容是短语或 A E S T H E T I C 式隔字，禁放正文数据。

## 禁令

- 禁朴素或正式的排版（这风格自己就不正经，但数据要正经）；禁硬边框锐利布局。
- 禁高饱和荧光色直接做正文字色；禁大面积纯色色块；禁让渐变变成混乱——色彩只活在 ambient 与点缀里。
- 禁 emoji；禁 AI 腔（口号式动词、营销形容词一律换成具体的曲名、年份与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是这场怀旧的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
