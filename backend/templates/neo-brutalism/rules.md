# 新野兽派 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律 900 粗黑（h1/h2 已内建），大且自信，可以直接全大写（英文标签统一大写）；
  元数据与出处用等宽字（nb-badge / nb-src / deck-footer 已内建）。
- 语气是「有态度的人话」：短句、口号可以喊，但每句都要有信息量；不讨好、不解释、
  不写客气话。
- 标题住在描边盒子里（nb-box）是本模板的招牌动作，一页至多一个盒子。

## 结构纪律（拳头要省着挥）

- 描边永远 3px 起、阴影永远零模糊（Npx Npx 0）；禁细线边框、禁模糊阴影、禁柔和颜色。
- 情绪色只有荧光橙、信号红、荧光黄三种：阴影按「黑 / 橙 / 红」轮换，节点按
  「奶油 / 橙 / 黄 / 红」轮换；一页实底色块不超过徽章 + 行动钮 + 通栏条三处。
- 卡片允许少量歪斜（nb-card / nb-tag 已内建旋转），但一页至多三张卡 + 页脚；
  卡与卡之间留足空隙，不做积木墙。
- 荧光笔划（nb-mark）只在 quote 的下半句用一次，是「喊出来」的那个词。

## 禁令

- 禁微妙的设计与柔和的莫兰迪色；禁圆角、渐变、玻璃拟态。
- 禁追求「优雅精致」：这是朋克摇滚，不是下午茶，但也禁堆满——留白就是态度。
- 禁 emoji；禁 AI 腔；禁编造精确数字——数据必须给口径与来源（nb-src 写在页尾）。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 呈现，数值 ≤6 字符；橙底焦点卡全份只给
  最重要的那一个数字。

## 节奏

- 提案顺序保持完整：cover → contents → metrics → divider → keynotes / split →
  moments → quote → closing（黑通栏条在首尾呼应）。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，是立场的压轴一拳。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与观点页穿插，不要连排。
