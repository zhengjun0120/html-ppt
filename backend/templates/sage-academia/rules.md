# 青竹 · 学术风 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板专业无衬线：标题近黑加粗（h1/h2 已内建），正文中性灰；唯一衬线位是引文页
  （sa-quote）。不要引入手写体、圆体或第二套衬线正文。
- 语言要「观察口吻」：先写看到的现象，再写它的分寸（像"电子书承担通勤，纸质书承担精读"），
  不堆抽象大词。
- 数字用无衬线细体呈现（sa-stat 已内建），不给数字加衬线。

## 结构纪律（绿意有分工）

- 鼠尾草绿只允许出现在四处：绿环编号（sa-no / sa-tl-dot）、关键数据（sa-stat-v / sa-tl-t）、
  强调药丸与题签短线（sa-pill-accent / sa-kicker-line）、收尾按钮（sa-btn）。青灰蓝只做题签
  小字（sa-kicker）。禁把绿色用于大标题或整卡底色。
- 卡只有一种：白面 + 细边 + 极轻阴影（sa-card）。禁厚阴影、禁深色底、禁立体特效。
- 留白即秩序：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。
- 右上大圆与左下圆环、虚线由模板自动衬底，正文不要手绘几何装饰。

## 禁令

- 禁 emoji；禁高饱和、荧光、撞色；禁深色或黑色背景，保持白底通透。
- 禁 AI 腔（「书香浸润」「赋能成长」一律换成具体的书名、动作与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 汇报顺序保持完整：cover → contents → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是汇报的「题记」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
