# 蓝橙经营图谱 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题正文一律无衬线（h1/h2 已内建系统黑体栈），等宽字（JetBrains Mono）只用于标签、编号、出处（bo-kicker / bo-src / bo-n / bo-tl-t / deck-footer 已内建）；不要给正文或大数字用等宽。
- 语气「结论先行」：标题给判断，正文给依据；经营动词要实（收、清、稳、砍），禁空喊。
- 英文标签全大写、只出现在题签与状态牌；中文数字混排时千分位与百分号规范书写。

## 结构纪律（赭红是警示，藏蓝是秩序）

- 赭红 #A13422 只允许出现在状态牌（bo-status）与口径文字中的「异常/目标」措辞，禁作大底色、禁给标题或正文上色、禁整卡赭红。
- 藏蓝实底只允许两处：KPI 看板块（bo-stat，结论级强调专用）与按钮（bo-btn）；题签药丸的藏蓝实底（bo-pill-accent）一页至多一枚。
- 卡只有一种：浅灰底 + 表格线灰描边（bo-card），像图表面板。禁强阴影、禁大圆角、禁具象插画。
- 阅读顺序固定：顶部结论（kicker + 标题）→ 中部主体 → 底部 KPI/来源，不要倒置。

## 禁令

- 禁 emoji；禁大面积深色背景、霓虹色、手绘或卡通插画。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体动作与数字）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁把所有指标做成同等大小的密集堆叠；一页只回答一个业务问题。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，口径与来源跟页走，不准埋进句子里。

## 节奏

- 标准顺序：cover → contents → metrics → divider → keynotes / split → moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是会议纪要的「定调一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
