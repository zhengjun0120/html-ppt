# 终端绿 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板等宽字体（JetBrains Mono + 中文等宽回落），h1/h2/h4 与正文都已内建，不要再引入别的字体栈；数字、命令、版本号天然等宽呈现。
- 语气要「终端的干脆」：写命令、输出、版本号与人话（像"冷启动 42 毫秒，比眨一次眼快 8 倍"），不写抽象大词。
- 中英混排保持短句；题签与标签里可以出现真实的命令与路径（$ brew install …、/etc/…）。

## 结构纪律（磷光是身份）

- 磷光绿只允许出现在：标题（h1/h2）、题签 $ 提示符、大数字（tg-stat-v）、时间点（tg-tl-t）、按钮与 accent 标签。禁把辉光用于正文段落——发光的文字一多就不亮了。
- 卡只有一种：半透明暗绿终端窗 + 绿描边（tg-card）。禁硬阴影、禁纯色亮底、禁大圆角。
- 一页最多两组内容块 + 页脚；终端美学靠留黑呼吸，不要塞满。
- 闪烁光标（tg-cursor）全份最多出现 2 次：封面与收尾各一次足矣。

## 禁令

- 禁 emoji；禁第二色相（红黄蓝紫一律不出现，扫描线与辉光都是绿）；禁非等宽字体。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁整页长代码、密集日志或多终端面板堆叠——代码是主角时只放一段（code 版式 6-10 行）。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → code → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是发布说明的「压轴一条」。
- divider 在 8 页以上的 deck 至少出现 1 次；code 一份 deck 至多 2 页，且要与数据页或内容页穿插。
