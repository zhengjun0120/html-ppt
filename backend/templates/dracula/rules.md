# Dracula 紫 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文用无衬线（Inter + Noto Sans SC，已内建）；题签、编号、时间点、代码块用等宽（JetBrains Mono，已内建）。不要引入手写体、圆体或衬线大标题。
- 语气要「工程师的设计分享」：写对比度、变量名、灰阶层级与人话（像"4.6:1，刚刚好过线"），不写抽象大词。
- 题签可以写真实的文件名与路径（// dark-mode.md、// src/theme/tokens.css）。

## 结构纪律（粉紫双色是身份）

- 荧光粉 #ff79c6 是主强调：题签、编号、大数字、按钮、accent 标签。薰衣草紫 #bd93f9 是次强调：注释符 //、时间线圆点与时间点、渐变线后半、语言标签。两色不得互换更不得混用第三种彩色。
- 冷白 #f8f8f2 只给标题（h1/h2/h4）与引言；正文一律银灰 #b3b8c3，禁把正文调成纯白。
- 辉光只给标题与荧光数字（dr-stat-v / dr-quote），正文与卡内文字不加发光。
- 卡只有一种：暗色半透明 + 蓝灰细描边（dr-card）。禁硬阴影、禁亮色底、禁整卡荧光。

## 禁令

- 禁 emoji；禁浅色背景、禁第三种色相的装饰（编辑器窗三圆点的蓝灰是唯一例外）。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁整页长代码或多窗并排——代码是主角时只放一段（code 版式 6-10 行）。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → code → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是复盘的「压轴一行」。
- divider 在 8 页以上的 deck 至少出现 1 次；code 一份 deck 至多 2 页，且要与数据页或内容页穿插。
