rules

三条铁律

不是反色

灰阶靠亮度差

白底黑字直接取反会刺眼。深色底用降饱和的浅灰，层级靠亮度差而不是色相。

重新调

强调色提亮

粉与紫在深底上会发闷。统一提亮一档、降一档饱和，才回到浅色时的辨识度。

换描边

阴影改浮层

深色底上阴影不可见。浮层改用细描边加表面提亮，层级一样清楚。

implementation

切换不是翻色值

切换不是把色值翻一遍：所有颜色先收进 CSS 变量，再按主题出两套映射，组件一行不改。

决定"暗在哪一层"的是背景与表面两个变量，文字色只跟着语义名走。

data-theme 零组件改动
01

硬编码色值全部收进变量，设计走查把关

02

深浅两套映射对齐同名变量，语义不换名

03

跟随系统与手动开关双通道，回滚只切开关

拾贝设计团队 · 2026
下一页是 tokens.css 的真实片段，就是这套映射的源头。

src/theme/tokens.css

主题只是一组变量

tokens.cssCSS
:root[data-theme="dark"] {
  --bg: #21222c;
  --surface: #282a36;
  --text-1: #f8f8f2;
  --text-2: #b3b8c3;
  --accent: #ff79c6;
  --accent-2: #bd93f9;
  --border: rgba(98,114,164,.25);
}

组件只读语义名：主题切换换的是变量值，对组件零侵入，回滚也只是换个 attribute。
