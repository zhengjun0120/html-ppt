# dracula（Dracula 紫）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/dracula`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。
（Dracula 本身是开源社区主题，上游 oh-my-ppt 对其做了深色演示向的适配。）

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：标题 #f8f8f2 冷白、正文 #b3b8c3 银灰，强调 #ff79c6 荧光粉与 #bd93f9 薰衣草紫
  是灵魂双色；背景 radial-gradient（#282a36 → #21222c → #191a21）；卡为
  rgba(40,42,54,0.8) + rgba(98,114,164,0.25) 蓝灰描边。
- 排版：等宽字体第一选择、代码友好；语法高亮在这个配色下自然发光。
- 装饰：右上紫晕 + 左下粉晕的辉光氛围；代码卡作视觉中心，布局克制。
- 适合：代码密集的技术分享、开源项目演示、编程教学、黑客马拉松。
- 禁忌：浅色背景、过多装饰分散对代码的注意力、改变核心配色、粉紫失去主角地位。

## 转换说明

- 上游只有一个 16:9 单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约重建为
  10 版式骨架（9 基础 + code，深色科技类按规范附加代码版式）。
- --bg 取背景渐变的中段值 #21222c：letterbox 底色随页面翻动不跳色。
- 紫晕与粉晕做成 .slide::before/::after 的 ambient 层（z-index:-1，纯 CSS 径向渐变），
  每页自动衬底、不进骨架；辉光只给标题与荧光数字，正文不加。
- 双色分工是本模板的身份纪律：粉=主强调（题签/编号/大数字/按钮），紫=次强调
  （// 注释符/时间线/渐变线/语言标签），全部对齐上游"粉紫不失主角地位"的要求。
- 字体栈：Inter（拉丁无衬线）+ Noto Sans SC（中文），代码/编号用 JetBrains Mono
  （随 fonts.css 自托管），不新增 webfont 文件。
- demo 叙事为原创（深色模式的界面设计），数据口径写在页内来源行。
