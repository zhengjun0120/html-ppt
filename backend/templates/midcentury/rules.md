# 世纪中叶 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律几何无衬线（h1/h2 已内建 Century Gothic/Futura 栈，宽字距），正文衬线焦糖色宽行距；
  小字标签与数字用等宽（mc-kicker / mc-n / mc-tl-t / deck-footer 已内建）。
  不要引入手写花体、像素字或现代科技感粗黑体。
- 语气要「客厅里的从容」：写器物、手感、光线与人话（像"先坐三秒，感受腰背被托住"），
  不写抽象大词，不用营销腔。
- 年份、编号、数据保持等宽呈现（模板已内建），不要给数字换衬线体。

## 结构纪律（三色各司其职）

- 芥末黄只出现在：题签圆点（mc-kicker 自带）、三色横条（mc-line）、数字块上缘（mc-stat）。
  青绿只出现在：药丸重音（mc-pill-accent）、行动钮（mc-btn）、题签文字。
  焦橙只出现在：关键数据（mc-stat-v）、时间点（mc-tl-t）。禁把任何一色铺成大面积色块或整卡底色。
- 卡只有一种：奶白 90% 底 + 淡焦橙细描边 + 10px 圆角（mc-card）。禁硬阴影、禁纯白死底、
  禁玻璃拟态。
- 有机形状是背景层：每页右上与左下由模板自动衬底，正文不要再手画形状、星爆或圆点阵。
- 留白即舒适：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。

## 禁令

- 禁 emoji；禁冷色调（蓝紫青灰）、金属渐变、玻璃拟态、霓虹光。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。
- 禁时代错位元素：不要出现 LED、触屏、赛博、极简北欧灰等现代意象。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 导览顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是设计师语录的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
