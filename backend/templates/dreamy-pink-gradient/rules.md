# 渐变美学·樱粉雾蓝 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题用圆润无衬线（h1 已内建樱粉→雾蓝渐变填充），正文无衬线宽行距；小字标签同族（dp-kicker / dp-pill / deck-footer 已内建）。不要引入衬线粗黑体、手写花体或截图式艺术字。
- 语气要「柔软但具体」：写颜色、纸感、光线与人话（像"樱粉是清晨，雾蓝是黄昏"），不写抽象大词。
- 数字用无衬线大号呈现（dp-stat-v 已内建渐变），不要给数字额外描边或阴影。

## 结构纪律（渐变是身份）

- 渐变只允许出现在五处：h1 大标题、关键数字 dp-stat-v、编号球 dp-n / dp-tl-dot、题签短线（dp-kicker 自带）、行动钮 dp-btn。禁把渐变用于 h2/h4/正文、整卡底色或整页背景。
- 月亮 dp-moon 是唯一的发光体，一页至多一枚；只放留白处，禁与正文文字重叠。
- 卡只有一种：磨砂半透明白 + 白描边 + 淡紫软阴影（dp-card）。禁深色卡、禁硬阴影、禁 backdrop-filter 玻璃拟态。
- 留白即柔光：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。

## 禁令

- 禁 emoji；禁荧光色、金属渐变、玻璃拟态、赛博霓虹。
- 渐变色不超过四档（樱粉 / 粉霞 / 薰衣草 / 雾紫蓝），深靛只做正文锚点；禁彩虹满铺。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 发布顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是星语时刻的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
