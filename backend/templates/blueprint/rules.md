# 蓝图 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全站等宽气质（h1/h2/正文已内建 JetBrains Mono 栈，中文回落 Noto Sans SC）；不要引入衬线体、圆体或手写体。
- 语气要「有图号的准确」：写尺寸、节点、责任人与人话（像"桩基 45 根，已初勘确认"），不写抒情大词。
- 数字是主角：关键量用 metrics 的引出线大数字承载，句子里不埋精确数字。

## 结构纪律（制图线是身份）

- 亮蓝线色（#60A5FA）只用于线稿：图签章、题签方点、编号框（bp-n / bp-tl-dot / bp-btn）、数据顶线（bp-stat）。禁把亮蓝铺成色块或整字高亮。
- 标注框只有一种：半透明暗蓝底 + 工程细描边（bp-box），框头是虚线图例行（bp-box-head）。禁圆角、禁阴影、禁暖色。
- 网格与双线图框每页自动衬底，正文不要手画网格；框内文字与图框保持呼吸距离。
- 图签章（bp-stamp）一页至多一枚，盖在封面、引言或收尾的重音处；它是审图章，不是装饰贴纸。

## 禁令

- 禁 emoji；禁暖色调、圆角、阴影、渐变彩色。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的图纸语言）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三框承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 框内说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 提案顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是图注的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
