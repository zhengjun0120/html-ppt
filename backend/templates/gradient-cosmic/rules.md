# 梦幻分界·星河烟火 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题粗体无衬线（h1/h2 已内建星白金晕），正文无衬线 Light 宽行距；引文走衬线斜体（gc-quote 已内建 Georgia/思源宋体）。小字标签用 500-600 字重宽字距（gc-kicker / gc-pill / deck-footer 已内建）。不要给正文换衬线，不要用圆体。
- 语气要「夜里守机位的人」：写器材、参数、时刻与人话（像"先学会等夜，再学会按快门"），不写抽象大词。
- 数字与英文用无衬线呈现（模板已内建），关键数字交给 metrics，不要埋进句子里。

## 结构纪律（金色是身份）

- 深色底纪律：正文一律浅色（星白 #F5F6FF / 浅紫灰 #C9CFF0 / 小字 #96A0D6），卡只有星夜卡一种（gc-card，金边强调用 gc-card-gold）。禁浅色实底卡、禁纯黑死底、禁在深底上用深色文字。
- 金色只允许出现在五处：题签短线（gc-kicker 自带）、大数字（gc-stat-v）、金色题签（gc-pill-accent）、行动钮（gc-btn）、金月（gc-moon）。禁把金色用于正文文字、大面积底色或整卡填充；强调金不超过亮金与火花橙两种。
- 星河、星点、流星与分界光带住在 ambient 层，由模板自动衬底；不要在骨架里手画星星、光带或烟火。
- 金月 gc-moon 只作装饰：一页至多一枚、只放留白处，禁在里面塞文字或当数据用。

## 禁令

- 禁 emoji；禁荧光色、卡通可爱、办公室商务风——这个风格必须有深色衬底，不要全亮无对比。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的器材、参数与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），参数类数字注明换算规则（如 500 法则）。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，口径写进块内或页尾。

## 节奏

- 夜课顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是金月最亮的一帧。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
