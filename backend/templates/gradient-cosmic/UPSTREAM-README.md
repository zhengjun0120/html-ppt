# gradient-cosmic（梦幻分界·星河烟火）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/gradient-cosmic`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：主色深靛蓝 #1A237E、暗夜黑 #000000、金橙 #FF9800；副色星金 #FFD700、暗紫 #0D1240、
  深蓝黑 #0A0E2C；文字星白 #F5F5F5、金米 #FFF3D6；强调亮金 #FFC400、火花橙 #FF6D00；
  背景为深靛到黑的夜空渐变（预览页为 115° 斜向多段渐变，右侧向金橙过渡）。
- 意象：星空、银河、烟火、光芒、剪影、流星；装饰用发光粒子、光线、星点、渐变光晕，
  预览页有分界光带（竖向金线）与金月母题，风格梦幻史诗、强明暗对比。
- 排版：标题粗体、星白色或金渐变填充；副标题细体金米色；正文无衬线 Light 行高 1.8。
- 动画：梦幻淡入、星点闪烁、金光缓慢流动、转场如夜幕切换。
- 禁忌：不全亮无对比（必须有深色衬底）；不低饱和灰暗、不要办公室商务风；不要卡通可爱；
  强调金不超过两种、保持克制。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 依任务定位把夜空推向「深紫蓝星河」：渐变主线取 #04050F → #0D1240 → #241A5E → #2E1B5C，
  右下角以 #FF9800/#FFC400 光晕收在金橙侧，保留上游「梦幻分界」的对角对比；
  分界光带（细金线 + 宽晕）与星点、流星一起画进 data-URI SVG ambient 层
  （.slide::before/::after，z-index:-1），每页自动衬底、不进骨架，生成侧零成本。
- 深色模板纪律：正文一律浅色（星白 #F5F6FF / 浅紫灰 #C9CFF0 / 小字 #96A0D6），
  卡为半透明深色底 rgba(9,12,38,.58) + blur + 金色细描边；--bg 取星河渐变中段值 #171B48，
  letterbox 与翻页过渡不跳色。金月收小为 96px 装饰件，只放留白处。
- 金橙渐变文字（gc-stat-v）两端为 #FFD700→#FF6D00，深底上全程高对比；
  行动钮为金火渐变实底配深墨字 #241300。引文走衬线斜体（Georgia/思源宋体），呼应上游诗意定位。
- 字体栈：Noto Sans SC / PingFang SC / Georgia / 思源宋体，无新增 webfont 文件。
- demo 叙事「星野摄影入门」：器材、参数（500 法则口径）与样片数据的来源
  均标注为拾光社 2026 年 3 月银河季样片 EXIF 汇总。
