# 企业洁净 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线（h1/h2 已内建 Inter + Noto Sans SC 重字重栈），正文常规字重、行距标准；不要引入衬线大字、手写体或等宽正文。
- 语气「结论先行、口径随后」：每页先给判断，再给依据；句子短、动词实，像备忘录不像海报。
- 数字用半角，千分位与百分号规范书写；英文缩写标签全大写、只出现在题签（cc-kicker）里。

## 结构纪律（海军蓝是身份）

- 海军蓝只允许出现在四处：页顶信头细线（自动衬底）、大数字（cc-stat-v）、按钮（cc-btn）、标识块（cc-badge）。禁把海军蓝做成整页底色或大面积色块。
- 辅助蓝 #3B82F6 只用于题签与药丸点缀；红、绿、紫、橙一律不用。
- 卡只有一种：白底 + 浅蓝灰描边 + 小圆角浅阴影（cc-card）。禁重阴影、禁大圆角、禁彩色底卡。
- 留白纪律：一页最多两组内容块 + 页脚；细分隔线（cc-rule / cc-item 底边线）是唯一的装饰语言。

## 禁令

- 禁 emoji；禁渐变彩底、玻璃拟态、花哨动画。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体动作与数字）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格与图表堆砌；对比类内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 标准顺序：cover → contents → metrics → divider → keynotes / split → moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是管理层定调的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
