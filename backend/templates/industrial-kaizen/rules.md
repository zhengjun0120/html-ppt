# 表格 · 现代周报 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板粗壮无衬线：h1/h2 用 800 字重、字距收紧 -.015em（模板已内建），正文 400；
  不要衬线、不要手写体、不要细字重标题。
- 语气像报表正文：短句、结论先行、有判断有数字；眉题用「栏目 + 周期」的全大写格式。
- **所有数字必须等宽数字**（模板已内建 tabular-nums）：KPI、金额、百分比、计数全部右对齐，
  多列数字要能视觉连成一条竖线；对齐错位比配色错误更严重。

## 结构纪律（零彩色，强线封边）

- 全模板禁彩色：状态一律用灰阶徽章表达——ik-badge-solid 实底反白（运营中/已关闭）、
  ik-badge-soft 浅底（观察/进行中）、ik-badge-line 描边（达成/关闭类结论）。
- 深墨强线 #1F1E1A 只允许三处：标题下沿（ik-rule）、KPI 横栏上下封边、按钮实底；
  行间一律 #EDE9DC 发丝线。禁阴影、禁渐变、禁圆角大于 2px、禁斑马纹。
- ▲▼ 趋势符只在 KPI note 处使用，一页一组；禁图标、禁插画、禁位图、禁 emoji。
- 一页最多两组内容块 + 页脚；密度由内容必要性决定，不为「报表感」硬塞行列。

## 禁令

- 禁任何彩色（红黄绿蓝紫橙一概不要；状态用底色深浅或文字标签表达）。
- 禁阴影、渐变、玻璃拟态、装饰性字体、花哨入场动画。
- 禁 AI 腔；禁无口径的精确数字（每个关键数字必须带统计口径与来源，写在页尾）。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁把数字埋进句子里：关键数据一律走 metrics（KPI 横栏）或 moments（周历）。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：KPI 与趋势走 metrics 横栏；日程与节点走 moments；卡内说明只放定性论断与必要的件数。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是报表卷首的扉页语。
- divider 在 8 页以上的 deck 至少出现 1 次；指标页与内容页穿插，先总览后归因。
