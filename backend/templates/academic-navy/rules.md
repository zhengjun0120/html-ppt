# 藏青学衡 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线：标题藏青加粗（h1/h2 已内建），正文深灰；小字标签与数字用等宽字体（an-kicker / an-tl-t / deck-footer 已内建）。不要引入楷体、手写体或第二套衬线标题。
- 语言要「证据口吻」：先说数据与口径，再下判断（像"双人在场读数，缺测率 2.1%"），不写抒情形容词。
- 英文题签用大写等宽（RESEARCH DEFENSE / CHAPTER 02），只做进度与索引，不承担内容。

## 结构纪律（金棕是身份）

- 金棕只允许出现在四处：关键数字（an-num / an-stat-v / an-tl-t / an-side-v）、强调药丸 an-pill-accent、题签小字 an-kicker、金顶线卡 an-card-gold（仅限引证场景）。禁把金棕用于大标题、大面积色块或整卡底色。
- 卡只有一种：白底 + 藏青顶线（an-card）。禁硬阴影、禁深色卡底、禁圆角大卡。
- 标题一律藏青（h1/h2 已内建），禁描金、禁渐变字；一页只允许一种强调方式。
- 左下六边形与右上金环由模板自动衬底，正文不要手绘几何装饰。

## 禁令

- 禁 emoji；禁糖果色、荧光色、玻璃拟态、金属渐变。
- 禁 AI 腔（「赋能」「抓手」一律换成研究的具体动作与对象）。
- 禁编造精确数字：关键数据必须给口径与来源（metrics 页尾、moments 页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比与并列内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 答辩顺序保持完整：cover → contents → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是答辩的「治学题记」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
