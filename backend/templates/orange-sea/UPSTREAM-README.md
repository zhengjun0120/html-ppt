# orange-sea（晴橙落日海）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/orange-sea`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色三件套：晴空蓝 #48C6F0、柔杏白 #FFF0D6、落日橙 #FF8A3D 做垂直渐变，模拟天空→
  云层→夕阳的自然过渡；深灰 #333333 标题正文、浅灰 #F0F0F0 分隔线；强调色落日橙
  突出关键数字与标签（上游预览的标题用深青蓝 #2A6B8A、橙色点缀词）。
- 排版：无衬线粗体（思源黑体 Bold）标题简洁有力，Regular 正文保持清晰；轻盈不轻浮。
- 意象：云朵、太阳、海鸥的简约线条绘制，轻微云层纹理（透明度 10%），波浪与倒影
  （预览中的 sun/cloud/gull/water/ripple 母题）。
- 布局：留白克制，左右/上下 ≥30%；色块标注 + 渐变背景组合，每页 1-2 个色块焦点；
  卡片大圆角与半透明白底（预览为 28px 圆角白卡）。
- 禁忌：高饱和霓虹、深暗色、硬朗几何与锐角、密集数据表、商务衬线粗体、塞满画面。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（白卡浮在海湾渐变上，无多版式结构）；本模板按
  本仓库 deck-v2 契约重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 「天空→海面」渐变 + 波浪纹 + 落日倒影整体做成 ambient 层（.slide::after inset:0），
  太阳、海鸥与云画在 .slide::before，z-index:-1 每页自动衬底；quote 页另飞一对海鸥
  （os-gulls）呼应上游线条母题。
- 渐变整体调浅一档（顶部 #48C6F0 收为 #B5E5F8 级），保证深海蓝 #1F6E96 标题与蓝灰正文
  全页可读；letterbox 底色取渐变中段 #F7ECD8，翻页不跳。落日橙做关键数字时收暗为
  #C2410C（浅底 ≥4.5:1）；题签橙胶囊内文字用深褐 #4A2508 保对比。
- 橙蓝撞色为骨架：橙给题签/数字/时间点，蓝给标题与 os-btn 按钮；不新增 webfont。
- demo 叙事改为「滨海城市文旅推广」（虚构小城澜港），覆盖上游 styleCase（旅游出行/
  疗愈冥想/教学科普）。
