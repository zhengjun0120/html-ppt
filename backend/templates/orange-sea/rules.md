# 晴橙落日海 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文一律无衬线（h1/h2 已内建 Bold 800），简洁有力、轻盈但不轻浮；小字标签用落日橙胶囊（os-kicker / os-pill / deck-footer 已内建）。禁衬线商务粗体与手写体。
- 语气要「海边慢半拍」的具体：写潮汐、灯塔、海风、骑行动线与人话，不写宏伟叙事大词。
- 数字与英文用无衬线呈现（模板已内建），关键数字交给落日橙。

## 结构纪律（橙蓝撞色）

- 落日橙只允许四处：题签胶囊 os-kicker、数据与时间点（os-stat 顶线 + os-stat-v / os-tl-t，已收暗为 #C2410C 保对比）、accent 药丸软底、太阳印 os-badge。禁把橙铺成整页色块或整卡底色。
- 深海蓝 #1F6E96 是标题与 os-btn 的骨架色——橙蓝互为撞色，一页里不许单边缺席。
- 卡只有一种：半透明白 + 大圆角 26px + 晴蓝调柔影（os-card）。禁硬阴影、禁锐角、禁密集数据表。
- 海鸥 os-gulls 只在 quote 页留白处一对，装饰不写字；一页最多两组内容块 + 页脚。

## 禁令

- 禁 emoji；禁高饱和霓虹、深暗色背景、硬朗几何与锐角。
- 禁密集数据表与商务衬线粗体——这是度假明信片，不是财务汇报。
- 禁把画面塞满：左右留白 ≥30%，让天空和海面透气。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的潮汐时刻、路线长度与渔村细节）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 对比类内容用 split 或 keynotes 的三卡承载，不排表格。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是海风里的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
