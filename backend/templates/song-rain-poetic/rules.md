# 宋人生活·听雨 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律宋体加粗气质（h1/h2 已内建宋体栈），副题与竖排短句用楷体（sr-vert / sr-seal 已内建），小字标签用无衬线（sr-kicker / sr-pill / deck-footer 已内建）。不要引入黑体粗标题、手写花体或圆体。
- 语气要「有体温的具体」：写器物、雨声、动作与人话（像"雨打芭蕉，风过青瓦"），不写抽象大词。
- 数字与英文用无衬线细体呈现（模板已内建），不要给数字加宋体楷体。

## 结构纪律（朱砂与暖黄是身份）

- 朱砂只允许出现在三处：印章 sr-seal、关键数据（sr-stat-v / sr-tl-t）、强调药丸与竖排点缀（sr-pill-accent / sr-vert-accent）。禁把朱砂用于大标题、大面积色块或整卡底色。
- 暖灯黄只允许出现在茶签卡左竖线（sr-tea）一处；嫩芽绿只出现在芭蕉 ambient 与雨线里，不手动画。
- 卡只有两种：宣纸半透明卡（sr-card）与暖黄左线茶签卡（sr-tea，仅限步骤条目场景）。禁硬阴影、禁纯白死底、禁圆角大卡。
- 留白是诗意的基础：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。
- 竖排 sr-vert 只放留白处，一页至多一条，内容是诗句或四字短语，禁放正文数据。

## 禁令

- 禁 emoji；禁高饱和荧光、赛博霓虹、金属质感、锋利几何。
- 禁暗黑沉重背景：这份模板的底永远是宣纸白与雾蓝，不做深色页。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 茶课顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是这场雨的「压轴一句词」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
