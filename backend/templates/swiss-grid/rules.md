# 瑞士网格 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律 900 大字（h1/h2 已内建），正文 17-22px 常规字重；小标签 700-800。
  索引、时间点、出处用等宽字（sg-i / sg-tl-t / sg-src / deck-footer 已内建）。
- 语气是「工作室宣言」：短句、判断句、可执行的规矩；禁营销形容词堆叠。
- 中英混排时，标签与通栏条里的英文全大写（INDEX / PORTFOLIO），正文保持中文语序。

## 结构纪律（红色是唯一出口）

- 正红只允许出现在：sg-kicker、sg-line、sg-square、sg-card-top、sg-stat-hot、
  sg-tag-red、sg-tl 节点、sg-btn、sg-bar。一页红色元素 ≤3 处，红线/红块是视觉锚点。
- 色块只有两种：正红块与近黑块（sg-square / sg-block），文字压在色块上必须白字且
  足够大（骨架已内建字号）；禁把色块当背景铺满整页。
- 卡只有一种：白卡 hairline 描边（sg-card），红顶线卡（sg-card-top）一组只允许一张。
- 全部直角：禁圆角、禁阴影、禁渐变纹理；外露网格线由模板衬底，正文不再画格子。

## 禁令

- 禁第二种强调色；禁衬线与手写体；禁自由布局——内容严格贴网格线排。
- 禁装饰性元素（图标、纹理、渐变、玻璃拟态）；红色承担全部情绪，别再叠加。
- 禁 emoji、禁 AI 腔；禁编造精确数字——数据必须给口径与来源（sg-src 写在页尾）。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 呈现，数值 ≤6 字符，红色只给最重要的那一个。

## 节奏

- 作品集顺序保持完整：cover → contents → metrics → divider → keynotes / split →
  moments → quote → closing（通栏条在首尾呼应）。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，是工作室立场的压轴宣言。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与作品页穿插，不要连排。
