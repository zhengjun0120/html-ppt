# 经典双色·米黄深蓝 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律衬线气质（h1/h2 已内建 Playfair + 宋体栈），正文宋体宽行距；数字与英文序号用衬线斜体（cd-n / cd-tl-dot / cd-stat-v 已内建），不要引入黑体粗标题或圆体。
- 语气「典籍感的人话」：句子可以短，但要沉；像年报致辞，不像促销海报。
- 金棕只作线与序号的颜色，不要给大段正文上金色。

## 结构纪律（双色是身份）

- 全模板只有两主色：暖米黄底 + 深海蓝字/块，金棕 #B8860B 只作细线、序号、题签描边点缀。禁第三种主色（红、绿、紫、亮橙一律不用）。
- 深海蓝大面积实底只允许三处：标识块（cd-badge）、书脊色块（cd-panel）、按钮（cd-btn）；禁整页深蓝底、禁米黄上的深蓝大色带。
- 卡只有一种：米色半透明底 + 深蓝细描边（cd-card），无阴影。禁玻璃拟态、禁大圆角、禁投影。
- 竖排 cd-vert 只出现在书脊色块内，一页至多一条，内容是四至七字短语，禁放数据。

## 禁令

- 禁 emoji；禁高饱和荧光、赛博霓虹、金属拉丝渐变、卡通可爱风。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体动作与数字）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁过度装饰：四角书角与暖调光晕已足够，骨架内不要再加纹样。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 标准顺序：cover → contents → metrics → divider → keynotes / split → moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是典籍的「题铭一页」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
