# 凝脂杨妃 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律宋体加粗（h1/h2 已内建宋体栈 + 中大字距），色名与展区名用楷体（pr-sw-name / pr-t / pr-stat-l 已内建楷体栈），拼音、hex 与小字标签用无衬线细字（pr-kicker / pr-sw-py / deck-footer 已内建）。不要引入黑体粗标题、手写花体或圆体。
- 语气要「器物的口吻」：温润、具体、有余韵（像"釉色沉在胎里，不浮在表面"），不写抽象大词。
- 拼音一律大写、无衬线小字；hex 是色值不是装饰，只出现在 pr-sw-hex。

## 结构纪律（釉色是身份）

- 杨妃粉只做"面上的一层釉"：顶部细带与缠枝（模板自动衬底）、釉线 pr-line、瓷圈 pr-n、hex pr-sw-hex、胶囊描边。禁大面积粉底整卡铺色。
- 胭脂只允许出现在五处：小印 pr-seal、强调胶囊 pr-pill-red、关键数据（pr-stat-v / pr-tl-t）、实底按钮 pr-btn、竖排重点字 pr-vert-accent。禁把胭脂用于大标题或整卡底色。
- 卡只有一种：暖象牙底 + 宣纸米细描边（pr-card），无阴影；釉色色卡 pr-swatch 是 keynotes 版式专属，别处不用。
- 留白即釉面：一页最多两组内容块 + 页脚；竖排 pr-vert 只放留白处，一页至多一条。

## 禁令

- 禁 emoji；禁暗黑背景、锋利几何、金属反光、赛博霓虹、荧光色。
- 禁现代无衬线粗体与传统色名混搭；色名一律楷体。
- 禁 AI 腔（口号式动词、营销形容词，换成具体的器物与人话）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 展线顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是瓷语的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
