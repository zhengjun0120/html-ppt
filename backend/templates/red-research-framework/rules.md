# 丹朱教研 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 全模板无衬线黑体（PingFang SC/Noto Sans SC）：标题红字加粗（h1/h2 已内建），正文灰字；
  品牌行、编号与时间点用等宽字体（rr-brand / rr-n / rr-tl-t / deck-footer 已内建）。
  不要引入衬线标题、手写体或圆体。
- 语言要「教研口吻」：讲机制、讲闭环、讲依据（像"任何调整先看巡查记录，再动课程池"），
  不喊口号；关键词只用红色突出一次。
- 副标题遵循「红字主标 + 灰字说明」的层级，不要用第二套强调色。

## 结构纪律（红是骨架不是墙纸）

- 丹朱红只允许出现在骨架元素上：标题带（rr-band）、编号（rr-n / rr-tl-dot / rr-num）、
  徽标（rr-badge）、关键数据（rr-stat-v / rr-stat 红左线）、强调药丸（rr-pill-accent）、
  按钮（rr-btn）、品牌行（rr-brand）。禁大面积色块墙；标题带每份 deck 至多两次。
- 金黄只做推进虚线与连接（rr-tl 连接线已内建），禁给标题描金、禁金黄大字。
- 卡只有一种：白底 + 2px 红描边（rr-card）。禁阴影、禁彩色卡底、禁圆角大卡；
  淡红底只给数据块（rr-stat）。
- 箭头与虚线只表达明确的顺序或依赖；右上六边形与左下金黄虚线由模板自动衬底，
  正文不要手绘连接线。

## 禁令

- 禁 emoji；禁冷淡色、马卡龙色、大面积深色背景。
- 禁 AI 腔（「赋能」「抓手」「闭环思维」换成具体的机制与动作）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；多模块并列用 keynotes 三卡，顺序流程用 split 或 moments 承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句做法 + 一句机制，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 汇报顺序保持完整：cover → contents → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是汇报的「教育题记」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
