# 新闻播报 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律加粗无衬线（h1/h2 已内建 Inter/Noto Sans SC 800 字重），行距紧凑、信息密度高；
  小字标签与时刻用等宽（nw-time / nw-n / nw-tl-t / deck-footer 已内建）。
  不要引入衬线大标题、手写体或圆体。
- 语气要「通报体」：写事实、时刻、责任人与动作（像"今晚八点前转移完毕"），
  不写抒情句，不用娱乐化表达。
- 数字与时刻保持等宽呈现（模板已内建），数据永远带口径。

## 结构纪律（正红是身份）

- 正红 #DC2626 只出现在：块号与时间线方块（nw-n / nw-tl-dot）、题签方块（nw-kicker 自带）、
  头条横幅左线（nw-banner 自带）、提示块重音（nw-pill-accent）、关键数据（nw-stat-v / nw-tl-t）、
  行动钮（nw-btn）、滚动条（nw-ticker）。深红 #7F1D1D 是标题色，暗红 #991B1B 是正文色。
  禁把正红铺成大面积底色（滚动条与块号这类"条与块"除外）。
- 卡只有一种：白底 94% + 红系细描边 + 硬阴影直角（nw-card）。禁圆角、禁柔影、禁玻璃拟态。
- 左侧红竖条与顶部红条由模板自动衬底，正文不要再画竖条或色带。
- 滚动条 nw-ticker 一页至多一条，只用于 cover / contents / divider / closing；
  快讯每条 ≤16 字，时刻列在行尾。
- 层级像播报：头条（nw-banner）→ 二条（卡片/数据）→ 三条（提示块），一页最多两组内容块 + 页脚。

## 禁令

- 禁 emoji；禁柔和粉彩、圆角设计、深色背景、暗黑模式。
- 禁 AI 腔（口号式动词、营销形容词一律换成通报体的人话）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。
- 禁轻松娱乐化排版：不要插画、不要吉祥物、不要表情符号式装饰。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 播报顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是通报会的「答问压轴」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
