# 鎏金象牙 · 高级质感 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律衬线（h1/h2 已内建 Georgia/宋体栈，大字距大字重），正文无衬线细体宽行距（lede / gi-d / gi-tl-d / gi-stat-note 已内建）；数字与年份用衬线大字（gi-stat-v / gi-n / gi-mark 已内建）。不要引入黑体粗标题、圆体或手写体。
- 可用少量英文衬线铭文做装饰（如系列铭、年号），一页至多一处；不写大段英文。
- 语气要「策展而非售卖」：写工艺、材质、出处与仪式（像"金水三浸三烤，色才沉得下去"），不写促销话术。

## 结构纪律（金线是身份）

- 双线金框与细密斜纹由模板自动衬底（.slide 伪元素），骨架与正文都不用画，禁再画第二道框。
- 鎏金棕只出现在大字与色块：h1/h2、gi-t、gi-quote、gi-stat-v、gi-mark、gi-btn、gi-pill-accent 底。香槟金只做细线与菱形花饰：gi-orn、gi-n、gi-stat 上缘线、gi-tl 连线、gi-pill 描边。禁第三种强调色。
- 金色渐变字 gi-gold 只许用于 h1/h2 的局部 2-4 字，全份 deck 至多 2 处；禁整段渐变、禁正文用渐变。
- 卡只有一种：半透明象牙底 + 香槟金细边框直角卡（gi-card）。禁硬阴影、禁大圆角、禁深底大卡（gi-mark / gi-btn / gi-pill-accent 的棕色块除外）。
- 对称与仪式感：一页最多两组内容块 + 页脚；不要塞第四块内容挤掉呼吸感。

## 禁令

- 禁 emoji；禁霓虹荧光、玻璃拟态、现代极简几何拼贴。
- 禁 AI 腔与促销话术（"尊享""爆款""限时特惠"一律换成具体的工艺与人话）。
- 禁密集 KPI 卡：数据最多三个一页，走 metrics 版式；禁在句子里埋关键数字。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁轻浮弹跳动画；模板已定沉稳翻页节奏，不要自加动画类。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现（衬线大字 + 口径 + 来源行）。

## 节奏

- 展览动线保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是「主理人题铭」的压轴一笔。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
