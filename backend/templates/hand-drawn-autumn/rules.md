# 手绘秋日旅行手账 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文一律圆体气质（h1/h2 已内建圆体栈，字重 800 压场）；小字标签同样是圆润无衬线（ha-kicker / ha-tag / deck-footer 已内建）。不要引入衬线宋体、黑体粗标题或手写花体。
- 语气要「手账主人的话」：写风、坡、味道、小意外与人话（像"风比车轮快"），不写抽象大词，可以有一点点孩子气的感叹。
- 情绪强调用彩色标签或色块词（ha-tag / ha-pill-accent 承载），不要靠加粗堆叠。

## 结构纪律（勾线是身份）

- 暖棕 #8B5E3C 是唯一勾线笔触：所有边框都是 2-2.5px 实线或虚线，圆角一律走模板内建的不规则值，不要再手写 border-radius。
- 南瓜橙 #E87D3E 只做焦点：大数字（ha-stat-v）、标签（ha-tag）、贴纸（ha-sticker）、按钮之一；砖红 #C04851 只做强调标签与按钮；天空蓝 #6BA3BE 每页至多一处，只做"清凉呼吸"。
- 卡只有一种：半透明白底 + 暖棕勾边的贴纸卡（ha-card）。禁硬阴影、禁纯白死底、禁对称规整圆角。
- 胶带 ha-tape 一页至多一条，压在卡顶或标题下；便利贴 ha-note 只在 quote 页右侧出现。

## 禁令

- 禁 emoji；禁渐变、3D、写实阴影——手绘风靠平涂与勾线。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格与网格化对齐——那是商务模板，不是手账；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 手账顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是扉页的「压轴一句」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
