三代方案

处理异步的三种姿势

第一代

回调函数

「做完叫我」最直觉，嵌套三层之后，错误处理与阅读一起崩塌。

第二代

Promise 链

把回调换成返回值，then 串起来；错误终于有了统一出口。

第三代

async/await

异步长得像同步，try/catch 直接可用，调试器也能跟上。

同一件事的三种写法

伪代码：把回拉直的过程

demo/pseudo.js伪代码
// 同一件事的三种写法（伪代码）
getUser(id, (err, u) => next(u))          // ① 回调
getUser(id).then(next).catch(onError)     // ② Promise
const u = await getUser(id)               // ③ await
const rs = await all([getA(), getB()])    // ④ 并发
// 有依赖才等待，无依赖就并行
