# 东京夜 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文用现代无衬线（Inter + Noto Sans SC，已内建），清晰但不张扬；数字、编号、时间点与代码一律等宽（tn-stat-v / tn-n / tn-tl-t / tn-tag / tn-codeblock 已内建）。
- 语气要有深夜的安静与能量：写依赖、等待、耗时与人话（像"有依赖才等待，无依赖就并行"），不写抽象大词。
- 正文对比度必须够亮（暗底上字要读得清，模板已内建蓝白正文），不要再压暗。

## 结构纪律（蓝是主光）

- 蓝只管主强调：题签细线、关键数字 tn-stat-v、编号 tn-n、按钮 tn-btn、时间线圆点。禁把蓝用于整卡底色或大面积色块。
- 紫只管强调药丸与时间点（tn-pill-accent / tn-tl-t），青只管终端标签与语言标签（tn-tag / tn-lang）；三色分工不互换，禁引入暖色。
- 卡只有一种：暗面板 + 蓝调细描边（tn-card）。禁纯白死底、禁重玻璃拟态、禁装饰堆叠——ambient 已内建两层，正文不再加光效。
- IDE 终端 tn-term 只在 code 版式出现，一份 deck 至多 1-2 页；代码 6-10 行、行长 ≤56 字符。

## 禁令

- 禁 emoji；禁暖色调、荧光绿、金属渐变、手写体与衬线大标题。
- 禁把暗色风格做得「活泼」：少装饰、少彩带，能量靠结构与留白。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的耗时、依赖与人话）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格与密集日志堆叠；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 建议顺序：cover → contents → divider → keynotes / split → code → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是夜里的「一句箴言」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排；code 版式全份 1-2 页。
