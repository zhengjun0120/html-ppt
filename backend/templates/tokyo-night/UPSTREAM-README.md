# tokyo-night（东京夜）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/tokyo-night`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：标题 #e2e8f0 冷白、正文 #cbd5e1 灰白，强调亮青与蓝是深夜屏幕上的两种光；
  背景从深灰蓝到近乎纯黑，模拟无月的夜空；卡片半透明暗色，边框如远处的霓虹。
- 排版：等宽或现代无衬线字体，带一点技术感；标题清晰不张扬，暗底对比度要够。
- 布局：暗色卡片浮在更暗的背景上，层级靠微妙的亮度差和边框区分；像 IDE 暗色主题，
  避免多面板与密集日志堆叠。
- 禁忌：暖色调、低对比正文、过多装饰元素、把暗色风格做得「活泼」。

## 转换说明

- 原上游只有一个 1600×900 的单页预览（无多版式结构）；本模板按本仓库 deck-v2 契约
  重建为 10 版式骨架（9 基础 + code 代码示例），属深色科技类模板的附加版式。
- 强调色按经典 tokyo-night 编辑器主题落地：夜蓝底 #1a1b26（与「东京夜」气质同源），
  霓虹蓝 #7aa2f7 管主强调、紫 #bb9af7 管次强调与时间点、青 #7dcfff 管终端/语言标签，
  三色分工写进 rules.md 的身份纪律；终端圆点用主题自己的红黄绿 #f7768e/#e0af68/#9ece6a。
- 上游预览的顶部霓虹渐变线与角部光晕，转写为 .slide::before 的顶部细线 + 辉光；
  页底城市天际线与零星灯窗是 .slide::after 的 data-URI SVG（z-index:-1，
  每页自动衬底，不进骨架），呼应「深夜便利店」的都市夜景意象。
- letterbox 底色 --bg 取径向渐变中段 #1a1b26，翻页与深浅过渡不跳色。
- 字体栈：正文与标题 Inter + Noto Sans SC，数字/代码/标签 JetBrains Mono（+ Maple 中日韩），
  均为仓库自托管字体，未新增 webfont 文件。
