# mountain-green-literary（山野葱郁）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的 `resources/styles/mountain-green-literary`
（Apache-2.0 License，其 NOTICE 要求保留归属，本文件即归属声明）。
页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：山的深绿 #3E7228 压住画面上半，浅绿 #408F77 做山峦中间过渡层；
  草地亮黄 #ECCB2D + 高光黄 #EFE32C 点亮下半；淡蓝绿 #CFDFCC 做平衡色与淡天空；
  纯白文字叠在深绿上，白色半透明做竖排诗句。绿黄对比强烈，有"盛夏正午"的灼热感。
- 母题：层次分明的远山（深绿→浅绿 2-3 层做纵深）、被阳光晒亮的黄绿草地、
  两个向远方奔跑的小孩背影、竖排诗句、圆形色卡阵列、手写签名式小字。
- 排版：粗笔手写大字（字重 800）压场；竖排细字诗句做文学留白；正文细无衬线；
  精髓是"一重一轻"——图重字轻的张力。禁大片蓝天主导、冷灰莫兰迪调、
  精致写实插画与卡通可爱风、几何无衬线粗体标题。

## 转换说明

- 原上游只有一个单页海报式预览（山/草/人的风景构图，无多版式结构）；本模板按本仓库
  deck-v2 契约重建为 9 版式骨架（cover/contents/keynotes/split/metrics/quote/divider/moments/closing）。
- 全页风景海报不可读，改为"淡草雾浅底 + 页底三层山峦草地 ambient"：深绿山与亮黄草
  压住画面下沿 240px 做身份层，正文留在浅底上保证投屏可读——图重字轻的张力由
  粗笔楷体大标题 + 细字正文 + 山形 ambient 共同承担。
- 手绘感全部用 CSS/SVG 实现：山峦草地是 data-URI SVG 的三层 path（preserveAspectRatio=none），
  飞鸟是手绘弧线，日光是径向渐变；色卡圆点编号按"松绿→浅绿→草黄→雾绿"轮换，
  复刻上游底部五圆形色卡阵列的意象。不用任何外部图片，不加 webfont。
- 草黄不做文字色（浅底上对比不足），只做标签底与荧光笔触，黄上配深字。
- 字体栈：标题 'STKaiti'/'KaiTi' 重字重楷体（粗笔手写感），正文 PingFang SC 细体；
  不新增 webfont 文件。
