# 山野葱郁 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律粗笔楷体气质（h1/h2 已内建楷体栈、字重 800），像毛笔压场的大字；正文细无衬线（字重 400），一重一轻拉开文学张力；小字标签无衬线加宽字距（mg-kicker / mg-pill / deck-footer 已内建）。不要引入现代几何无衬线粗体做标题。
- 语气要「有文学性的夏天」：写山、风、蝉鸣、晚凉与人话（像"山静日长"），不写抽象大词；可以有稚拙，但不要甜。
- 竖排诗句（mg-vert）只放留白处：四字短语或七字以内的一句，禁放正文数据。

## 结构纪律（山绿是身份）

- 深绿 #3E7228 是身份色：描边、编号圆点、大数字（mg-stat-v）、按钮（mg-btn）；浅绿 #408F77 只做色卡圆点与山峦过渡，淡蓝绿 #CFDFCC 只做雾色点缀。
- 草黄 #ECCB2D 是阳光：只做笔触与标签底（mg-chip、mg-stat-l 的荧光笔划），黄上必须配深字，禁草黄文字、禁大面积黄底。
- 卡只有一种：纸白 + 山绿软描边 + 不规则圆角（mg-card）。禁硬阴影、禁纯白死底、禁把内容色块压进页底山形里再叠色。
- 页底山峦草地是 ambient：它属于画面不属于内容，任何卡片、按钮都不准再用绿黄渐变模仿它。

## 禁令

- 禁 emoji；禁大片蓝天主导、冷灰莫兰迪调、精致写实插画与卡通胖软风。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 山野顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是手记的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
