# 复古电视 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律衬线大字（h1/h2 已内建 Georgia/宋体栈，宽字距），正文焦糖色宽行距；
  小字标签、编号与时刻用等宽（rt-kicker / rt-n / rt-tl-t / deck-footer 已内建）。
  不要引入现代无衬线粗标题、像素游戏字或霓虹光效字。
- 语气要「客厅里的旁白」：写节目、记忆、时间与人话（像"那时全家挤在一台 fourteen 寸电视前"
  换成"全家挤在一台十四寸电视前"），不写抽象大词，怀旧但不滥情。
- 数字与时刻保持等宽呈现（模板已内建），排播与收视数据永远带口径。

## 结构纪律（琥珀是身份）

- 深琥珀 #D97706 只出现在：频道签 LED 与文字（rt-kicker 自带）、频道角标（rt-badge）、
  数字块上缘（rt-stat）、药丸重音（rt-pill-accent）、行动钮（rt-btn）。
  关键数字与时间点用更深的琥珀棕 #B45309 保证可读。禁把琥珀铺成大面积色块或整卡底色。
- 卡只有一种：CRT 屏幕圆角卡（rt-screen，22px 圆角 + 内辉光）。禁直角硬卡、禁玻璃拟态、
  禁现代极简白卡。
- 圆角屏框、扫描线、辉光、雪花噪点、底部旋钮由模板自动衬底，正文不要再画扫描线、
  电视机边框或噪点贴图。
- 一页最多两组内容块 + 页脚；内容像电视画面一样框在屏幕里，四周留出"外壳"呼吸感。

## 禁令

- 禁 emoji；禁冷色调、过强的纯黑对比、金属渐变、赛博霓虹。
- 禁 AI 腔（口号式动词、营销形容词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 split 或 keynotes 的三卡承载。
- 禁过度数字化：不要让页面看起来像 App 界面，保留手工排版的温度。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 企划顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是台长寄语的「压轴一笔」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
