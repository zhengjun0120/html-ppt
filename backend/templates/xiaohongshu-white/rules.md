# 小红书白 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。
注意与「极简白」（minimal-white）区分：那份是克制的线条与字重，这份是社媒的活泼——
贴纸、书签、话题标签、荧光划重点，衬线标题是两种白共同的只有这一份有的灵魂。

## 字体与语言

- 标题一律衬线（h1/h2/h4 与 xh-t / xh-stat-l 已内建 Georgia + 宋体栈），像生活方式杂志
  内页；正文无衬线宽行距。禁无衬线粗体做标题，禁给正文上衬线。
- 语气要「笔记体」：写亲测过程与前后对比（像"发布前发给三位老粉丝试读"），有个人口吻，
  不写机构腔；关键词可用 xh-mark 荧光划重点，一页至多两处。
- 数字用衬线呈现（模板已内建），像杂志版面上的编辑数字。

## 结构纪律（暖红是点缀）

- 暖红 #F56565 只允许出现在书签（ambient 自带）、贴纸签（xh-tag）、关键数据
  （xh-stat-v / xh-tl-t / xh-tl-dot）、强调签（xh-pill-accent）与话题标签（xh-hash）。
  禁大面积红底、禁给整卡上红、禁红正文长段落。
- 卡只有一种：近纯白白卡 + 极淡红描边 + 珊瑚左条（xh-card）；琥珀暖卡（xh-card-warm）
  一页至多一张，用于需要「暖一下」的那张。禁深色卡、禁硬直角。
- 实底贴纸签（xh-tag）一页至多一枚，日期/章名等次级信息一律虚线款（xh-tag-soft）。

## 禁令

- 禁 emoji；禁冷色调、科技感元素、暗色背景（白底的干净是这份模板的命）。
- 禁 AI 腔（"赋能增长"换成"发布 24 小时后定下一步"这种做过的动作）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；清单类内容用 keynotes 三卡或 split 右卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚
  （deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里；收藏行（xh-like）
  里的数字必须与页尾口径一致。

## 节奏

- 笔记顺序保持完整：cover → contents → metrics / divider → keynotes / split → moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是这篇笔记的「扉页」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
