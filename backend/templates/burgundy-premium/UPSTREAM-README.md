# burgundy-premium（勃艮第红高级感）

**来源归属**：本模板的视觉概念（配色、装饰母题、风格气质）提取自开源项目
[arcsin1/oh-my-ppt](https://github.com/arcsin1/oh-my-ppt) 的
`resources/styles/burgundy-premium`（Apache-2.0 License，其 NOTICE 要求保留归属，
本文件即归属声明）。页面结构、CSS、demo 与版式契约为本仓库从零手写，未复制上游代码。

## 上游风格要点摘录（原 SKILL.md 大意）

- 配色：勃艮第红主色定调（上游 #81021F，深红偏紫、饱和度高明度克制），纯黑做底放大
  红的醇厚；玫瑰金 #F8B37F 做主标题与关键符号，拿坡里黄 #FDD95F / 明黄做点缀，
  深灰 #363636 平衡，晴山蓝 #093D77 小面积互补。
- 意象：极细玫瑰金水平线（1px）做章节分隔、圆角标签色块、方形字母徽记、克制的留白——
  「一眼能看出贵，而不是堆砌金光」。
- 排版：粗壮几何无衬线大标题（宽字距 0.08–0.15em）+ 中等无衬线正文；色号标注用
  圆角色块内小字。
- 动画：cubic-bezier(0.22,0.61,0.36,1) 强 ease-out，0.6–1.0s，金线从左向右展开；
  不弹跳、不旋转、不闪烁。
- 禁忌：浅色、粉嫩、马卡龙色；手写体；高饱和荧光；花哨插画与 emoji；
  大面积留白配小字；超过四种主色同铺。

## 转换说明

- 上游只有一张 16:9 单页预览（左酒红块 + 右色卡阵列的杂志封面式布局）；本模板按
  本仓库 deck-v2 契约重建为 9 版式骨架（cover/contents/keynotes/split/metrics/
  quote/divider/moments/closing）。
- 主色定调改用任务指定的勃艮第 #5E1224（上游 #81021F 收深一档）：整页酒红渐变的
  中段值同时充当 letterbox 底色（--bg），翻页不跳；正文文字改奶白衬线系，
  对酒红底对比度 ≥8:1，小字灰 #B79E8A ≥5:1。
- 金色统一收成香槟金 #C9A063 / 亮金 #E8C08E 两档（替代上游玫瑰金+拿坡里黄的暖色群）：
  金只出现在细线、描边、徽记与关键数据，贴合「金色细线做唯一装饰语言」的转换目标。
- 页面四周金细框（.slide::before）与页角橡木桶年轮（.slide::after，data-URI SVG，
  z-index:-1）每页自动衬底，不进骨架。
- 字体栈：标题/正文 Georgia + 宋体（奶白衬线字），小字标签与页脚 Inter/Noto Sans SC；
  不新增 webfont 文件。
