# 勃艮第红高级感 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题与正文一律奶白衬线（h1/h2/lede/bg-quote 已内建 Georgia+宋体栈）；小字标签、数字与页脚用无衬线细体（bg-kicker / bg-pill / bg-tl-t / deck-footer 已内建）。不要引入无衬线粗黑大标题、手写体或圆体——衬线是这套模板的贵气来源。
- 语气要「沉得住」：写年份、产区、杯中变化与待客细节（像「醒到第四十分钟，它才肯开口」），不写「奢华」「尊享」「殿堂级」这类营销形容词。
- 数字与英文用无衬线呈现（bg-stat-u / bg-tl-t 已内建），年份写全四位；价格与席位数必须带口径。

## 结构纪律（金线是身份）

- 金色只允许出现在细处：bg-kicker 细线、bg-rule 金线、bg-mark 徽记、bg-n / bg-tl-dot 描边、bg-btn 描边、关键数据（bg-stat-v / bg-tl-t / bg-pill-accent）。禁大面积金色、禁金色大标题、禁金色底卡。
- 卡只有一种：深色半透明 + 金细边（bg-card）。禁白色卡、禁彩色底卡、禁大圆角卡、禁硬阴影。
- 页面四周的金色细框与页角橡木年轮是模板自动衬底的 ambient 层，骨架与正文都不要重画边框。
- 奶白是唯一的亮色面：标题、正文都用奶白系（--ink/--ink-2），亮金只给数字与强调；页面底部是酒红渐变，禁深色文字（对比度不达标会被门禁打回）。
- 留白克制但不空：一页最多两组内容块 + 页脚；深色底自带视觉重量，不要塞满。

## 禁令

- 禁 emoji；禁粉嫩马卡龙色、荧光色、玻璃拟态、金属渐变大色块。
- 禁 AI 腔：营销形容词一律换成具体的风土、年份与侍酒细节。
- 禁编造精确数字：评分、年份、配额、价格必须给口径与来源（写在页尾）；没有来源就写区间或「以当日为准」。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；酒款对比用 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-200 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：年份、席位数、价格、评分一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 晚宴顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是晚宴的「题酒词」。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
