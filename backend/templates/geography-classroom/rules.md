# 地理课堂·蓝图 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题用稳重黑体（h1/h2 已内建 Noto Sans SC 重字重），引文与谚语用宋体/Georgia（ge-quote 已内建）；小字标签用无衬线（ge-kicker / ge-pill / deck-footer 已内建）。不要引入书法体、圆体或细弱字体。
- 语气像课堂讲解：先提问，再给证据，最后落结论。写「从这幅图上看……」「考点在这里」，不写抽象大词与营销形容词。
- 数字与英文由无衬线呈现（模板已内建）；海拔、温差、降水量必须带单位，年份写全四位。

## 结构纪律（蓝是结构，红黄是批注）

- 海军蓝只用于结构：标题、编号块 ge-n、时间线圆点 ge-tl-dot、按钮 ge-btn；青绿负责讲解与题签（ge-kicker / ge-line / ge-tl-t / 卡片顶带）。
- 珊瑚红只允许出现在关键数据：ge-stat-v / ge-tl-t / ge-pill-accent。禁把珊瑚红用于大标题、大面积色块或整卡底色。
- 明黄只允许出现在 ge-tag 标签，一页至多两枚。禁大面积黄底，禁珊瑚红与明黄大面积相邻。
- 卡只有一种：白底图册卡 + 青绿顶带（ge-card）。禁硬阴影、禁大圆角卡、禁彩色底卡。
- 留白即图面：一页最多两组内容块 + 页脚；经纬网与等高线是模板自动衬底的 ambient 层，骨架与正文都不要重画。

## 禁令

- 禁 emoji；禁霓虹色、玻璃拟态、厚重 3D、通用商务图库风。
- 禁 AI 腔：口号式动词换成课堂人话与具体地名（「季风」「秦岭—淮河」「等高线」优先于「赋能」「格局」）。
- 禁编造地理数据：数值必须给口径与来源（写在页尾）；没有权威来源就写教材页码，或用「约」与区间。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；区域比较用 split 或 keynotes 的三卡承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句结论 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；页码页脚（deck-footer）每页都保留。
- **数字纪律**：考点数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 课堂顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是课堂收束前的一句点题。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与讲解页穿插，不要连排。
