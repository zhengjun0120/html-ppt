# 青绿湖蓝 · 质量规则（生成阶段注入）

本文件是这份模板的专属质量规则，与 layouts.md 的版式锁配合使用。

## 字体与语言

- 标题一律宋体加粗气质（h1/h2 已内建宋体栈），卡题与正文黑体（h4、ft-d 已内建）；
  数字与英文一律无衬线（ft-card-num / ft-stat-v / ft-tl-t 已内建），不要给数字套宋体或楷体。
- 语气清朗直接：像自然导师对家长和孩子说话，写具体的东西、动作与数字，
  不写「赋能」「沉浸式体验」这类营销形容词。
- 副题、题签用无衬线小字宽字距（ft-kicker / ft-pill / deck-footer 已内建）。

## 结构纪律（三色是身份）

- 翠竹绿、湖蓝、淡米三色只允许出现在：顶部三色条（ft-band）、圆点编号
  （ft-n / ft-tl-dot，配色由 nth-child 自动轮换，不要手工改）、实色三联卡
  （ft-card-green / ft-card-blue / ft-card-ink）、数据顶线（ft-stat）。
- 朱红只允许四处：印章 ft-seal、题签短线（ft-kicker 自带）、关键数据
  （ft-stat-v / ft-tl-t）、强调药丸（ft-pill-accent）。禁把朱红用于大标题或大面积色块。
- 卡只有两种：实色三联卡（keynotes 专用，一页至多一组）与淡色细线卡（ft-panel）。
  禁硬阴影、禁纯白死底、禁大圆角卡片，几何直角是这份模板的现代感来源。
- 每页骨架第一行的三色条照抄不要删；右下山峦是模板自动衬底，正文不要画山。

## 禁令

- 禁 emoji；禁高饱和荧光、禁暗黑背景、禁复杂渐变、禁金属质感。
- 禁超过四种主色——三色协奏 + 朱红点睛已是全部，不要自造配色。
- 禁 AI 腔（口号式动词、空泛大词一律换成具体的人话与场景）。
- 禁编造精确数字：数据必须给口径与来源（写在页尾），没有来源就写区间或量级。
- 禁一页多个破折号「——」；引文出处行允许一个。
- 禁高密度表格；对比类内容用 keynotes 三卡或 split 承载。

## 密度

- 每页可见文字 90-220 字；低于下限会被写入门禁直接拒收。
- 卡片说明 22-44 字：一句论断 + 一句展开，句号结尾的完整句。
- **每页要有下半区**：量测会检查填充率，内容只占画布一半不到的页会被打回；
  页码页脚（deck-footer）每页都保留。
- **数字纪律**：关键数据一律 metrics 或 moments 呈现，不准埋进句子里。

## 节奏

- 手册顺序保持完整：cover → contents → divider → keynotes / split → metrics / moments → quote → closing。
- 同一版式最多连用 2 页；quote 全份 deck 出现 1 次，它是全篇的定调一笔。
- divider 在 8 页以上的 deck 至少出现 1 次；数据页与内容页穿插，不要连排。
