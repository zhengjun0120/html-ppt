# 模板标签归并：227 → 40 规范标签

日期：2026-09-30。动机：标签筛选上线（docs/template-filter-plan.md）后实测词表 227 个、
长尾大量 count=1，「更多」折叠到 28 个也仍然琐碎。本次把同类/近义标签归并成 40 个
规范标签，让 chip 行一行放下、每个标签都有筛选价值。

## 规则

- 合并：同义（深色/暗色）、家族从属（国风/水墨/青瓷）、近似观感（粉彩/樱粉/奶油）。
- 丢弃：纯用途词（周报/复盘/测评）、单一色号（冰蓝/酒红/薄荷绿→归入家族或丢）、
  与 scenario 重复的词（技术分享/年度总结）。丢弃的前提是模板保留其余标签——
  迁移脚本强制断言每个模板归并后 tags 非空。
- 用户 fork 模板（ut-*）保留 fork 时刻的标签快照，不在归并范围内（用户数据）。

## 迁移方式与后续

- 一次性脚本 `tmp/merge-tags.py`（干跑 + --apply）：只对 template.json 的 tags 行做
  行级替换，多行 tags 数组统一为行内格式；断言单行唯一匹配、无未映射标签、
  每模板归并后非空。
- 校验：`go test ./internal/service/template/`（注册表加载 101 模板）、
  前端 vitest 数据契约守卫（tags 非空）全过。
- 生效：注册表启动时加载，改完须重启后端进程。
- **以后新增模板请直接使用上表的规范标签**；新词先想清楚是否值得成为第 41 个规范标签。
