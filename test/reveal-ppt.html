01 · 为什么用 HTML 写幻灯片

核心能力一览

（本页内容正在逐条"分步显示"——这就是 Fragment 功能）

  • 🎯 横向 / 纵向导航：左右翻主章节，上下进子页面
  • ✨ 多种过渡动画：slide / fade / zoom / convex / cube
  • ⌨️ 代码语法高亮：内置 highlight.js 插件
  • 🎤 演讲者视图：按 S 查看备注与下一页
  • 📄 一键导出 PDF：直接打印成讲义

02 · 核心能力一览

几行 HTML 就能跑


<link rel="stylesheet" href="dist/reveal.css">

<div class="reveal">
  <div class="slides">
    <section>第一页</section>
    <section>第二页</section>
  </div>
</div>

<script src="dist/reveal.js"></script>
<script>
  Reveal.initialize({ transition: 'slide' });
</script>
每个 <section> 就是一页幻灯片，嵌套即可实现纵向子页面。

放映时的实用按键

按键作用
→ / 空格下一页（或下一个 Fragment）
←上一页
↓ / ↑进入 / 返回纵向子页面
S演讲者视图（备注 + 预览下一页）
F全屏放映
O幻灯片总览模式
